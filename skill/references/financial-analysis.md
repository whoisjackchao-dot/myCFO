# 财务报表分析与经营诊断

## 一、三张表的勾稽关系（先验数，再分析）

| 关系 | 公式 | 用途 |
|---|---|---|
| 会计恒等式 | 资产 = 负债 + 所有者权益 | 资产负债表自检 |
| 利润结转 | 期末未分配利润 = 期初未分配利润 + 本期净利润 − 分红/提取 | 利润表 → 资产负债表 |
| 现金勾稽 | 现金流量表期末现金 = 资产负债表"货币资金" | 两表对不上就是账没平 |
| 收入成本 | 毛利 = 营业收入 − 营业成本 | 利润表 |
| 现金流间接法 | 经营现金流 ≈ 净利润 + 折旧摊销 − 营运资金增加 | 解释"利润≠现金" |

**30 秒自检**：随便挑一期，把资产负债表、利润表、现金流量表按上面 5 条对一遍；任一条不成立，先查账，不要往下分析。

## 二、核心比率（按用途分组）

### 盈利能力

| 指标 | 公式 | 参考线（小微） |
|---|---|---|
| 毛利率 | (收入 − 成本) / 收入 | 服务 ≥50%，贸易 ≥20%，制造 ≥25% |
| 净利率 | 净利润 / 收入 | ≥5% 健康，<5% 抗风险弱 |
| 费用率 | (销售+管理+财务费用) / 收入 | 与自身历史比，环比升 5 个点要查 |
| ROE | 净利润 / 平均所有者权益 | ≥15% 优秀 |
| ROA | 净利润 / 平均总资产 | 与行业比 |

### 偿债能力

| 指标 | 公式 | 参考线 |
|---|---|---|
| 流动比率 | 流动资产 / 流动负债 | ≥1.5 |
| 速动比率 | (流动资产 − 存货) / 流动负债 | ≥1.0 |
| 现金比率 | 货币资金 / 流动负债 | ≥0.3 |
| 资产负债率 | 总负债 / 总资产 | ≤70%（小微宜 ≤50%） |
| 利息保障倍数 | 息税前利润 / 利息费用 | ≥3 |

### 营运能力

| 指标 | 公式 | 参考线 |
|---|---|---|
| 应收账款周转天数（DSO） | 应收账款 / (收入/30) | ≤60 天 |
| 存货周转天数（DIO） | 存货 / (营业成本/30) | 贸易 ≤60 天 |
| 应付账款周转天数（DPO） | 应付账款 / (营业成本/30) | 越长越好，但不能逾期 |
| 现金转换周期（CCC） | DSO + DIO − DPO | 越短越好；>60 天说明被营运资金锁死 |

### 成长与质量

| 指标 | 公式 | 说明 |
|---|---|---|
| 营收增速 | (本期 − 上期) / 上期 | 连续 2 期负增长要预警 |
| 净利增速 | 同上 | 净利增速 < 营收增速 = 费用/成本恶化 |
| 经营现金流 / 净利 | 经营活动现金净流量 / 净利润 | ≥1 说明利润是真钱；长期 <0.5 是危险信号 |
| 应收增速 vs 营收增速 | 应收增速 − 营收增速 | 应收涨得比收入快 = 在放宽账期换收入 |

## 三、杜邦拆解

```
ROE = 净利率 × 总资产周转率 × 权益乘数
    = (净利/收入) × (收入/总资产) × (总资产/权益)
```

- 净利率低 → 查成本、费用、定价
- 周转率低 → 查应收、存货、资产闲置
- 权益乘数高 → 查负债结构，杠杆是否过头

**小微企业的常见结论**：ROE 看起来不低，其实是权益乘数（借钱/欠款）撑起来的，净利率和周转率都在恶化。要拆开看。

## 四、现金漏斗（解释"赚钱但没钱"）

```
净利润
+ 折旧摊销（不付现的成本）
− 应收账款增加
− 存货增加
− 预付款增加
+ 应付账款增加
+ 预收款增加
= 经营活动现金流净额
```

逐项问：
1. 净利去哪了？→ 算 CCC，看被哪个科目锁住。
2. 应收是谁欠的？→ 拉账龄表，按客户排序。
3. 存货是不是呆滞？→ 看库龄和动销率。
4. 老板有没有从公司拿钱？→ "其他应收款"科目是常见藏身处。

## 五、经营诊断树

```
利润为正但现金少
├─ 应收增加 > 收入增加        → 账期错配，收紧信用政策
├─ 存货增加 > 成本增加        → 备货过度/滞销，清库存
├─ 应付减少（提前付款）       → 付款节奏太松，谈账期
├─ 其他应收款增加             → 股东占款/押金，限期清理
└─ 投资支出大                 → 扩张节奏问题，看回本周期

毛利率下降
├─ 售价降（竞争/让利）        → 提价或做高毛利产品
├─ 成本涨（采购/人工）        → 重新议价、换供应商
└─ 收入结构变（低毛利占比升） → 调整产品/客户结构

净利率降但毛利率稳
├─ 人员成本增                 → 人效（收入/人）是否下降
├─ 费用失控                   → 逐项拆销售/管理/财务费用
└─ 一次性支出                 → 区分经常性与非经常性

收入增长但利润不增
├─ 获客成本高                 → 算 CAC 与 LTV
├─ 低价单多                   → 算单笔订单毛利
└─ 返工/售后成本高            → 查交付质量
```

## 六、口径提醒

- 分析用**不含税收入**，否则毛利率被增值税扭曲。
- 小微企业的"净利润"要区分税前/税后；用税后看真实留存。
- 一次性政府补助、资产处置收益要从"可持续利润"里剔除。
- 月度数据波动大，至少看 3 个月移动平均再下结论。
