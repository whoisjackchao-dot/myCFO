# 预算与现金流管理

## 一、年度预算（12 个月，按季滚动）

自上而下做三张表，自下而上用业务假设校准：

| 表 | 关键行 | 做法 |
|---|---|---|
| 收入预算 | 客户数 × 客单价 / 项目数 × 项目金额 | 分存量客户、新客户；给保守/基准/乐观三档 |
| 成本费用预算 | 直接成本、人工、房租、市场、其他 | 人工按编制表；固定费用按合同 |
| 现金预算 | 回款计划 − 付款计划 − 税费 | 按账期排到周 |

**编制顺序**：业务目标 → 收入 → 成本 → 费用 → 利润 → 回款 → 现金流 → 缺口 → 融资/砍支。

**月度滚动**：每月实际数出来后，更新"未来 3 个月"的预测，不改历史。

## 二、13 周现金流预测（缺钱时最有用的工具）

原理：13 周 = 一个季度，覆盖小微企业两个账期，能提前看到断点。

```
期初现金
+ 确定回款（按合同/账期逐笔排周）
+ 其他流入（贷款、投资款，只算已确定的）
− 固定支出（工资、房租、社保、贷款月供，按周摊）
− 应付账款（按到期周逐笔排）
− 税费（按申报期预留）
= 各周期末现金
```

规则：
1. **只算已确定/高概率的钱**（回款概率 ≥80% 才进表），不确定的单列"观察池"。
2. 每周期末现金 < **安全垫**（≥ 1 个月固定支出，理想 3 个月）就标黄，<0 标红。
3. 表要短：一页纸，13 行，每周一行，老板能一眼看到哪周见底。

**输出模板**（`scripts/checkup.py` 会自动生成）：

| 周次 | 流入 | 流出 | 期末现金 |
|---|---:|---:|---:|
| 第 1 周 | | | |
| … | | | |
| 第 13 周 | | | |

## 三、保本点与安全边际

```
边际贡献率 = (收入 − 变动成本) / 收入
保本收入   = 固定成本 / 边际贡献率
安全边际率 = (实际收入 − 保本收入) / 实际收入
```

- 安全边际率 < 20%：收入稍微下滑就亏损，要提前准备。
- 固定成本越高，保本点越高，抗风险越差 —— 能外包的别自建，能提成的别底薪。

## 四、回款管理（现金的第一来源）

1. **账期分级**：新客户 ≤30 天，老客户 ≤45 天，超过 60 天的客户要审批。
2. **催收节奏**：到期前 3 天提醒 → 到期日确认 → 逾期 7 天电话 → 逾期 15 天发函 → 逾期 30 天停单。
3. **考核挂钩**：销售提成按回款发，不按签单发。
4. **客户信用表**：按历史回款记录分级（A/B/C），C 类客户先款后货。
5. 每周看 DSO（应收周转天数），目标 ≤45 天。

## 五、缺钱时的 5 个杠杆（按优先级）

| 杠杆 | 动作 | 见效速度 |
|---|---|---|
| 回款 | 催逾期货款、给提前付款折扣、把大客户拉到预付 | 1–2 周 |
| 付款 | 和供应商谈账期（30→60 天）、分期、票据 | 2–4 周 |
| 库存 | 清呆滞库存、按需采购、代销/寄售 | 2–8 周 |
| 费用 | 砍非必要开支、推迟招聘、外包替代 | 立即 |
| 融资 | 银行小微贷、税贷、供应链金融、股东借款（走合规手续） | 2–8 周 |

**顺序很重要**：先回款、再谈账期、再砍费用，最后才是融资。融资是买时间，不是解决问题。

## 六、预算差异分析

每月对比：实际 vs 预算 vs 上月，拆成：

```
差异 = 量差 + 价差 + 结构差
收入差异 = (实际销量 − 预算销量) × 预算单价 + 实际销量 × (实际单价 − 预算单价)
费用差异 = 实际 − 预算（按科目逐项，超过 10% 或 5000 元要解释）
```

只解释两类差异：**金额大**的、**会持续**的。一次性小差异不用管。

## 七、常见错误

| 错误 | 后果 | 纠正 |
|---|---|---|
| 把"签单"当"回款"做预算 | 现金流预测过于乐观 | 按账期和回款概率折算 |
| 安全垫按"月支出"算，不按"含税款的月支出" | 交税时才发现没钱 | 把季度税款平摊进每月固定支出 |
| 只做年度预算不滚动 | 3 个月后就失真 | 每月滚动 3 个月 |
| 预算和考核不挂钩 | 预算变成纸面文章 | 销售、采购、费用都挂预算 |
