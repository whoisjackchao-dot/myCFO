# 电商会计处理（CPA 视角，小企业会计准则）

> 适用：执行《小企业会计准则》（财会〔2011〕17 号）的电商小微企业。
> 若公司执行《企业会计准则》，差异处单独标注。
> 本文件给"怎么做账"，不给"怎么申报"（申报见 `references/ecommerce-tax.md`）。

## 一、先定会计政策（一次性，写进档案）

| 事项 | 小企业会计准则 | 备注 |
|---|---|---|
| 存货计价 | 先进先出 / 加权平均 / 个别计价 | 服装 SKU 多，推荐**月末一次加权平均** |
| 存货跌价 | **不计提跌价准备** | 实际毁损、报废、滞销处理时计入营业外支出 / 销售费用 |
| 坏账 | 不计提坏账准备，实际发生时直接转销 | 平台欠款风险低，主要是退货纠纷 |
| 所得税 | 应付税款法 | 不确认递延所得税 |
| 收入 | 总额法（自营） | 代销/平台代收用净额法，见下 |
| 增值税 | 价税分离；免税部分按当地口径处理 | 免税销售额可全额确认收入，或分离后转营业外收入，**选定后保持一致** |

### 收入确认：总额法还是净额法

判断标准：**转让给客户之前，公司是否控制了商品**。

| 模式 | 方法 | 收入口径 |
|---|---|---|
| 自营（自己备货、定价、承担存货风险） | 总额法 | 售价全额 |
| 代销/分销（平台/供应商控制商品） | 净额法 | 只确认佣金/服务费 |

服装电商自营店一律**总额法**；只有做"帮别人卖货抽佣"时才用净额法。

**确认时点**：买家确认收货（或系统自动确认）时确认收入；发货但未确认收货的，挂"发出商品"或按平台规则处理。预收款（预售、定金、礼品卡）先记"合同负债"，发货/收货后再转收入。

## 三、典型分录（按业务流）

### 1. 买家下单付款、商家发货（确认收入）
```
借：其他货币资金—平台账户        含税金额
    贷：主营业务收入              不含税金额
        应交税费—应交增值税        税额（小规模 = 含税/1.01×1%）
```
> 若当月符合免税条件：全额计入主营业务收入，不分离税额。

### 2. 平台结算、提现到对公账户
```
借：银行存款
    贷：其他货币资金—平台账户
```

### 3. 平台佣金 / 技术服务费 / 支付手续费
```
借：销售费用—平台佣金
    应交税费—应交增值税（进项税额）   ← 取得专票时
    贷：其他货币资金—平台账户
```

### 4. 快递费、包装费
```
借：销售费用—快递费 / 包装费
    贷：银行存款 / 应付账款
```

### 5. 退货退款（小企业准则简化：冲减当期）
```
借：主营业务收入（红字）
    应交税费—应交增值税（红字）
    贷：其他货币资金—平台账户
同时：
借：库存商品（可二次销售的部分）
    销售费用—退货损失（不可销售/折价）
    贷：主营业务成本
```
> **不要**只冲收入不冲成本，否则毛利率失真。

### 6. 采购入库（档口无票也要入账）
```
借：库存商品
    贷：银行存款 / 应付账款
```
> 无票不影响会计入账，只影响**企业所得税税前扣除**；内部必须留存采购单/付款记录/收货单。

### 7. 投流费
```
借：销售费用—推广费
    应交税费—应交增值税（进项税额）   ← 取得专票
    贷：银行存款 / 预付账款
```

### 8. 达人佣金 / 坑位费
```
借：销售费用—达人佣金
    贷：银行存款 / 其他应付款
```
> 支付给个人的佣金，公司有**代扣代缴个人所得税**义务（劳务报酬或经营所得，看合作形式）。

### 9. 平台保证金
```
借：其他应收款—保证金
    贷：银行存款
```

### 10. 月末结转成本与计提
```
借：主营业务成本
    贷：库存商品
借：管理费用—工资 / 销售费用—工资
    贷：应付职工薪酬
借：税金及附加
    贷：应交税费—应交城建税/教育费附加/地方教育附加
```

## 四、月末结账 10 步（电商版）

1. **导账单**：各平台导出结算明细、退款明细、推广费明细。
2. **三方对账**：平台账单 ↔ 银行流水 ↔ 账面收入/费用，差异列清单（见第五节）。
3. **确认收入**：按净成交额（扣退款）确认，价税分离。
4. **冲减退货**：收入与成本同步冲减。
5. **结转成本**：按加权平均单价 × 出库数量。
6. **归集费用**：平台费、快递、包材、推广、达人佣金逐项核对。
7. **核对库存**：账面库存 vs 仓库/云仓实盘，差异查原因（漏记入库、退货未入库、盘亏）。
8. **清理往来**：保证金、平台待结算、应付快递/供应商。
9. **计提税费**：增值税、附加税费、企业所得税预缴、个税。
10. **出表 + 分析**：三表 + 单元经济 + 现金流预测。

## 五、成本核算（服装电商）

### 成本构成（进"库存商品"的部分）
采购价（小规模按含税全额；一般纳税人按不含税）+ 入仓运费 + 随货包装 + 改标/熨烫等加工费。

**不计入成本**（属销售费用）：平台佣金、投流、发给买家的快递费、达人佣金、退货运费。

### 计价方法：月末一次加权平均（推荐）

```
加权平均单价 = (期初金额 + 本期入库金额) / (期初数量 + 本期入库数量)
出库成本     = 出库数量 × 加权平均单价
```

- 记账可按"款号"汇总，管理报表按"款号×颜色×尺码"拆分。
- 不要用"售价倒推成本"，也不要估一个毛利率了事。

### 无票采购的成本台账（必须做）

| 日期 | 供应商 | 款号/品名 | 数量 | 单价 | 金额 | 付款方式 | 凭证 | 有票 |
|---|---|---|---|---|---|---|---|---|

- 月末与库存、银行/微信流水三方核对。
- 这张台账是证明"成本真实发生"的唯一底稿；没有它，税务上只能全额调增。

### 退货入库
- 可二次销售：按原成本转回库存商品。
- 不可销售/折价：差额转"销售费用—退货损失"。
- 跨月退货：小企业准则下冲减当期收入与成本（不追溯）。

### 盘点与差异
- 每月抽盘 10% 的 SKU，季末全盘。
- 盘亏：管理不善计入管理费用；非常损失计入营业外支出（留存证据）。
- 盘盈：冲减管理费用。

### 跌价
小企业准则**不计提**跌价准备；季末清仓时按实际售价与成本差额计入销售费用/营业外支出；税务上存货损失需留存证据并按规定申报。

## 六、月度报表编制要点

### 利润表（电商结构）

```
营业收入（净成交，不含税）
− 营业成本（结转的库存成本）
= 毛利
− 销售费用（平台佣金/推广费/快递费/包装费/达人佣金/退货损失）
− 管理费用（工资/房租/办公）
− 财务费用（手续费/利息）
− 税金及附加（附加税费/印花税）
= 营业利润
+ 营业外收入（政府补助/免税转入）
− 营业外支出（盘亏/滞销处理）
= 利润总额
− 所得税费用（应付税款法）
= 净利润
```

### 资产负债表关键科目
货币资金、其他货币资金（平台待结算/可提现）、应收账款（平台已确认未结算）、其他应收款（保证金）、存货、应付账款、应付职工薪酬、应交税费、其他应付款（达人佣金/平台费）。

### 现金流量表（间接法简化）

```
经营现金流 = 净利润 + 折旧摊销 − 存货增加 − 应收增加 + 应付增加
电商特有调整：平台在途货款变动、保证金变动、投流预付变动
```

### 三表勾稽自检
1. 期末未分配利润 = 期初 + 净利润 − 分红
2. 货币资金 + 其他货币资金（期末）= 现金流量表期末现金
3. 存货余额 = 库存台账金额（差异要逐笔查）

## 七、三方对账与常见差异

| 差异类型 | 表现 | 处理 |
|---|---|---|
| 平台扣点差异 | 账单扣费 ≠ 账面佣金 | 按账单调整，差额查明是否含活动服务费 |
| 退款跨期 | 本月退款冲上月收入 | 按会计期间归属；金额小的当期冲减 |
| 运费险/补贴 | 平台代收代付 | 单列"其他应收/应付—平台" |
| 提现手续费 | 银行/平台收取 | 财务费用 |
| 在途货款 | 已发货未结算 | 挂"应收账款—平台"，不要提前确认现金 |
| 刷单/异常订单 | 无真实物流或集中退款 | 不得确认收入；已确认的要冲回 |

**对账公式**：
```
平台账单结算金额 + 平台待结算余额变动
= 银行实际到账 + 平台费用扣款 + 退款 + 保证金变动
```
对不上就逐笔查，不要用"调平"方式硬做。

## 八、常见错账（稽查与审计最爱抓）

1. 用 GMV 确认收入，不扣退款。
2. 退货只冲收入不冲成本，毛利率虚高。
3. 平台佣金、投流费、快递费不入账（以为"平台自动扣了"）。
4. 无票采购不入账 → 账面成本偏低、利润虚高、库存账实不符。
5. 保证金计入费用。
6. 老板个人卡收货款，账外循环。
7. 跨期确认收入（12 月订单拖到 1 月，或反之）调节利润。

## 九、与企业会计准则的差异（若适用）

| 事项 | 小企业准则 | 企业准则 |
|---|---|---|
| 存货跌价 | 不计提 | 计提跌价准备 |
| 收入 | 简化 | 五步法、可变对价、退货负债 |
| 所得税 | 应付税款法 | 资产负债表债务法（递延所得税） |
| 政府补助 | 营业外收入 | 其他收益/递延收益 |
