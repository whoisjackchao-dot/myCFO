# 电商零售（服装：卫衣/内衣）经营模型

> 适用范围：拼多多、淘宝/天猫为主的 B2C 服装零售，小规模或临界规模。
> 数字来源：`company-ops-research/ecom-platforms.md`（2026-10 核实，标注置信度）。平台规则会变，**落库前以后台账单为准**。

## 一、GMV ≠ 营业收入：一张桥表

```
成交额 GMV（含税、含运费）
− 退款/退货金额
− 商家承担的优惠券/满减
= 净成交额（GMV_net，含税）
÷ (1 + 征收率)          ← 小规模 1%，一般纳税人 13%
= 营业收入（不含税）
```

费用侧（进"销售费用"或"营业成本"）：
平台佣金/技术服务费、支付手续费、运费险、快递费、包装费、投流费、达人佣金、退货运费/损耗。

**最常见的三个错**：
1. 用 GMV 当收入 → 虚增 40%–80%（服装退货率极高）。
2. 忘了扣退货，或只扣退款金额没扣退货运费、折价损耗。
3. 把平台扣点当"收入减少"而不是费用 → 利润表结构错。

## 二、平台参数速查（服装类目）

| 参数 | 拼多多 | 淘宝 | 天猫 | 抖音 | 京东 |
|---|---|---|---|---|---|
| 佣金/技术服务费 | 0.6% | 0.6% | **5%（服饰）+0.6% 基础软件服务费** | 5%（活动期可降至 0.6%） | 5%–8% |
| 账期（约） | 17–19 天 | 10–25 天 | 10–25 天 | 4–30 天（按体验分） | T+1 ~ 6 天 |
| 退货是否退佣金 | 按比例退 0.6% | — | — | 活动返佣到千川 | 退佣金 |
| 特点 | 低价走量、价格敏感 | 搜索/内容，C 店费低 | 品牌化，扣点最高 | 直播驱动，退货率最高 | 自营物流，账期最快 |

**三条结构性事实**（比费率更重要）：
1. **退货率是最大变量**：女装货架电商 50%–60%，直播/达播 70%–85%（经济日报 2026-10）。扣点在 0.6%–8% 摆动，退货率在 40%–80% 摆动，**后者的影响是前者的 5–10 倍**。
2. **投流是预付制**：先充值后消耗，且是现金支出；达人佣金是"确收后付"，滞后于货款（对现金流是正向）。
3. **仅退款已收紧**（2025-04 起各平台陆续取消/改商家自主协商），但**退货率没有下降**，退货退款入口仍在。

## 三、平台账期与现金流

回款链条：

```
买家付款 → 资金进平台 → 发货 → 确认收货（或系统自动确认）
→ 平台结算可提现 → 提现到对公账户
```

现金占用（缺钱时真正要算的）：

```
退货准备金 = 日均退款额 × (账期天数 + 售后期天数)
平台现金占用 = 在途货款 + 保证金 + 投流账户余额 + 达人预付/坑位费
```

**算例**：月确收 60 万、退货率 55%、账期 18 天、售后期 15 天 → 退货准备金约 36 万，而保证金通常只有 0.5–2 万。**把注意力放在保证金上是错配，真正压钱的是退款池与投流预付。**

## 四、单元经济（每卖一单真正赚多少）

```
不含税净收入 = 售价 ÷ (1+征收率) × (1−退货率)
变动成本     = 成本×(1−退货率) + 平台费×净成交 + 快递/包材 + 退货物流
边际贡献     = 不含税净收入 − 变动成本
贡献率       = 边际贡献 ÷ 不含税净收入
单件净利     = 边际贡献 − 分摊投流（广告费 ÷ 总订单数）
保本 ROAS    = 1 ÷ 贡献率
保本售价     = 使边际贡献 = 0 的售价（投流为 0 时）
```

**决策规则**：
- 实际 ROAS < 保本 ROAS → 这个款投流就亏，先提价/降成本/降退货率。
- 安全垫（售价 − 保本售价）< 10% → 没有降价空间，别参加大促。
- 贡献率 < 40% → 结构脆弱，退货率一涨就亏。
- 达播费比 ≥35% 时（坑位费+佣金+投流），服饰专场毛利率可能只剩个位数——接达播前先按本模型算一遍。

工具：`scripts/ecom_unit_econ.py`（单品 + 多 SKU ABC/售罄 + 退货敏感性）。

## 五、库存与 SKU（服装的命门）

| 指标 | 公式 | 参考线 |
|---|---|---|
| 库存周转天数 | 平均库存 ÷ (月均销售成本/30) | 服装 60–90 天 |
| 动销率 | 有销量 SKU ÷ 总 SKU | ≥70% |
| 售罄率 | 累计销量 ÷ (累计销量+库存) | 季末 ≥80% |
| 退货率 | 退款订单 ÷ 成交订单 | 女装货架 50%–60%，直播 70%–85%；卫衣同量级；内衣无权威数据（通常更低），用自身历史 |
| 滞销库存占比 | 90 天无销量库存金额 ÷ 总库存 | ≤15% |

**卫衣的季节节奏**（强季节性）：
- 8–9 月：备货（占全年库存 50%+），投流测试款
- 9–12 月：旺季，主推款加库存
- 1–2 月：清仓（回款优先，接受低毛利）
- 3–7 月：淡季，控制备货，测新款

**内衣的长尾**：尺码×颜色组合多，用"安全库存 + 快返"代替大批量备货；断码比断货更伤转化。

**不可回避的跌价**：季末清仓价低于成本时毛利为负；预算里按库存金额 5%–15% 预留损失。

## 六、指标参考（判断异常用，不是行业标准）

| 指标 | 参考区间 |
|---|---|
| 平台费率（综合 take rate） | 拼多多/淘宝 0.6%–1%；天猫 5.6%；抖音 5%；京东 5%–8% |
| 退货率（卫衣/女装货架） | 50%–60%（直播 70%–85%） |
| 投流费比（占确收） | 10%–30% |
| 达人佣金率 | 20%–30%；达播费比 ≥35% |
| 履约成本（快递+包材+退货运费） | 占 GMV 5%–10% |
| 毛利率（售价口径） | 45%–65% |
| 净利率 | 3%–12% |

> 如果老板报的退货率明显低于 40%，先质疑数据口径：是不是只统计了"退款金额"、没统计退货订单？是不是把仅退款的单剔除了？

## 七、增长期现金流陷阱（爆量反而缺钱）

```
GMV 增长 → 备货增加（提前 1–2 个月付现金）+ 投流预付
         → 平台货款 15–25 天才到账 + 退货准备金
         = 增长越快，现金缺口越大
```

判断公式：**每增加 100 万月 GMV，需要额外垫多少现金？**
≈ 备货增量 + 投流增量 − 平台结算增量（约 GMV × 账期/30）

卫衣旺季前 2 个月，这个数通常是月 GMV 的 30%–50%。"接得住爆量"的前提是提前备好现金。

## 八、平台差异（策略选择）

| 维度 | 拼多多 | 淘宝/天猫 |
|---|---|---|
| 流量逻辑 | 低价+爆款+活动，价格敏感 | 搜索+内容+店铺权重，品牌溢价空间大 |
| 退货政策 | 2025-04 后商家自主协商，退款入口仍在 | 七天无理由为主 |
| 费用结构 | 0.6% 低费率，但活动让利大 | 0.6%（C 店）/ 5.6%（天猫） |
| 适合策略 | 走量、清库存、测款 | 做品牌、做复购、做客单价 |
