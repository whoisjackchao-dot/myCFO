# 电商服装（卫衣 / 内衣）小微企业：会计处理与税务合规笔记

> **适用对象**：中国大陆，年营收 3,000 万以下，主营卫衣、内衣、家居服等服装品类，通过天猫/淘宝、抖音、拼多多、京东、视频号或自建小程序销售，含自营、平台代销、达人直播、一件代发等模式。
> **默认会计口径**：《小企业会计准则》（财会〔2011〕17 号）。需要融资、并购、集团合并或上市规范的，改用《企业会计准则》（下称“新准则”）。
> **数据快照**：2026-10-24。**政策时效**：《增值税法》及实施条例自 2026-01-01 施行；小规模 1%、季度 30 万免征、小微 5% 所得税、六税两费减半均执行至 2027-12-31。
> **免责**：本笔记是实务参考，不构成税务/法律意见。政策会变，申报前以电子税务局、主管税务机关口径为准；涉及总额/净额、平台补贴、达人佣金定性等争议事项，建议提前与税务师或主管税务机关沟通。
> **口径**：本笔记“小微企业”是增值税小规模纳税人 + 企业所得税小型微利企业的统称，两者条件不同，须分别判断。

## 0. Skill 调用提示（可直接复制）

**触发词**：服装电商、卫衣、内衣、淘宝/天猫/抖音/拼多多/京东、直播带货、退货、刷单、无票采购、平台对账、GMV、投流、达人佣金。

**先问 6 件事**（缺什么问什么，一次问完）：

1. 纳税人身份：小规模还是一般纳税人？按月还是按季申报？是否有多个主体/店铺？
2. 经营模式：自营、平台自营供货、代销/分销、一件代发、达人直播？谁定价、谁发货、谁承担退货？
3. 规模：年 GMV、营业收入、退货率、客单价、毛利率大致多少？
4. 采购：面料/成衣从工厂、档口还是自然人采购？能否取得发票？税率几个点？
5. 费用：平台佣金/技术服务费、投流费、达人佣金/坑位费、快递费各多少？是否有合同和发票？
6. 会计准则：小企业会计准则还是企业会计准则？是否已用 ERP/进销存？

**输出顺序**：先判断总额/净额 → 再算 GMV 到收入的桥 → 再给分录 → 再算税 → 再列风险与对账清单。

**不要做**：两套账、买发票、刷单、私卡收款、虚列运费/包材、把达人劳务报酬硬转成个体户经营所得。

## 1. 商业模式决定会计模型

### 1.1 五种常见模式

| 模式 | 谁控制商品 | 谁定价 | 谁承担存货/退货 | 收钱方式 | 收入确认 |
|---|---|---|---|---|---|
| 自营（品牌/白牌） | 商家 | 商家 | 商家 | 平台代收后结算 | **总额法** |
| 平台自营（采销/供货） | 平台 | 平台 | 平台 | 平台按供货价结算 | 商家按 **B2B 供货价** 确认，不按 GMV |
| 代销/分销 | 委托方/供应商 | 委托方 | 委托方 | 商家收佣金 | **净额法**（只确认佣金） |
| 一件代发 | 看合同：商家是否控制商品 | 商家或供应商 | 看合同 | 平台结算 | 控制→总额；否则净额 |
| 达人直播 | 商家 | 商家 | 商家 | 平台结算，达人收佣金 | 商家总额；达人净额 |

> **关键**：同一家公司可能同时存在多种模式。**必须分店铺、分模式、分 SKU 核算**，不能把自营 GMV 和代销佣金混在一个“主营业务收入”里。

### 1.2 总额法 vs 净额法：看“转让前是否控制商品”

《企业会计准则第 14 号——收入》第三十四条（财会〔2017〕22 号）的判断标准：

> 企业应当根据其在向客户转让商品前是否拥有对该商品的控制权，来判断其从事交易时的身份是主要责任人还是代理人。能够控制商品的，为主要责任人，按已收或应收对价**总额**确认收入；否则为代理人，按预期有权收取的**佣金或手续费**确认收入。

**三个辅助迹象**（不是独立标准，要综合看）：

1. **主要责任**：谁对质量、售后、退换货、缺货赔付负责？
2. **存货风险**：谁承担滞销、跌价、丢失、毁损？
3. **定价权**：谁决定最终售价？能否自主调价、做活动？

**判断树**：

```
商品转让前，商家能否自主决定：
  ├─ 选品、采购、定价、库存、发货、售后 → 是 → 主要责任人 → 总额法
  └─ 只负责引流/展示/撮合，商品由供应商或平台控制 → 否 → 代理人 → 净额法
```

**常见争议**：

- **一件代发**：如果商家自己选品、定售价、承担退货和售后，即使由供应商直接发货，通常仍是主要责任人 → **总额法**；如果只是把订单转给供应商、价格由供应商定、商家不承担存货风险 → **净额法**。
- **平台“自营”**：京东自营、天猫超市等由平台采销，平台是主要责任人；商家是供货方，按供货价确认收入，**不能把平台零售价当自己的收入**。
- **达人直播**：商家是主要责任人 → 总额法；达人是代理人 → 净额法（佣金/坑位费）。

> **平台代收 ≠ 平台代销**：平台只是代收代付货款（资金先到平台、再结算给商家），商家仍是主要责任人，用总额法；只有平台/供应商控制商品、商家只收佣金时，才用净额法。

**对报表的影响**：

| 项目 | 总额法 | 净额法 |
|---|---|---|
| 营业收入 | 大（含商品全价） | 小（只含佣金） |
| 毛利率 | 低（有商品成本） | 高（无商品成本） |
| 平台佣金 | 销售费用 | 不单独列示（已抵减收入） |
| 增值税 | 按货物 13%/1% 全额 | 按经纪代理服务 6%（小规模 1%/3%） |
| 适用 | 自营、品牌店 | 代销、纯撮合、部分一件代发 |

### 1.3 GMV 与营业收入：四个口径不要混

| 口径 | 含义 | 常见用途 |
|---|---|---|
| 下单 GMV | 用户提交订单的金额（含未支付、取消） | 运营看板，最虚 |
| 支付 GMV | 实际支付的订单金额（含后续退款） | 投流 ROI 常用 |
| 结算 GMV | 平台扣除退款、佣金、补贴后与商家结算的金额 | 对账 |
| 营业收入 | 会计确认的、不含税、扣除退货/折扣后的净额 | 财务报表、报税 |

**桥接公式（总额法）**：

```
营业收入（不含税）
= [支付 GMV − 退款 − 商家承担的优惠 − 代收代付运费]
  ÷ (1 + 税率或征收率)
```

> 如果手上是“下单 GMV”，还要先减未支付/取消订单，再套上式。

**净额法**：

```
营业收入（不含税）= 佣金/服务费收入 ÷ (1 + 6%或1%/3%)
```

**示例**：支付 GMV 1,000 万（假设无未支付/取消），退款 300 万，商家承担优惠 50 万，含税净成交 650 万。

- 小规模 1%：营业收入 = 650 ÷ 1.01 = **643.56 万**，增值税 6.44 万。
- 一般纳税人 13%：营业收入 = 650 ÷ 1.13 = **575.22 万**，销项税 74.78 万。

> **一句话**：GMV 是“顾客点了多少钱”，营业收入是“公司真正赚到、且不含税的钱”。两者差 30%–50% 在服装电商很正常，不是账做错了。

### 1.4 收入确认时点

| 场景 | 会计确认时点 | 依据/说明 |
|---|---|---|
| 现货发货 | 通常按“签收/确认收货”确认；发货即转移控制权的按发货 | 新准则看控制权；小企业准则看风险报酬转移 |
| 附 7 天无理由退货 | 签收/确认收货时确认，同时估计退货（新准则） | 不能等退货期满才确认 |
| 预售/定金 | 收款时记合同负债；发货/签收时确认收入 | 定金不退的，按合同判断 |
| 平台代收 | 收入确认早于平台结算，用“应收账款—平台”过渡 | 结算单是收款依据，不是收入确认依据 |
| 跨年发货 | 12 月发货、次年 1 月签收：按控制权转移判断；年末未签收可记“发出商品” | 需要与增值税纳税义务时间分开看 |

**增值税纳税义务时间**（《增值税法》第二十八条）：收讫销售款项或取得索取销售款项凭据的当日；先开票的，为开票当日。预收款销售货物，通常在**货物发出**时产生纳税义务（实施条例第三十九条），不是收款时。因此会出现“会计记合同负债、增值税已应税”的时间差，申报时要单独台账。

## 2. 收入的会计分录

> 以下分录默认**小企业会计准则**；新准则差异在 2.4 说明。所有金额单位为元。

### 2.1 自营总额法（小规模纳税人，1%）

**场景**：含税售价 101 元/件，销售 1,000 件，含税 101,000 元；成本 50 元/件，共 50,000 元；平台佣金 5%（5,050 元）；支付手续费 0.6%（606 元）；快递费 8 元/件（8,000 元）；投流 10,000 元；达人佣金 3,000 元（个人，代扣个税 440 元）。

**① 发货确认收入**

```
借：应收账款—平台/店铺            101,000
  贷：主营业务收入                  100,000
      应交税费—应交增值税            1,000
```

**② 结转成本**

```
借：主营业务成本                    50,000
  贷：库存商品                        50,000
```

**③ 平台结算（扣佣金、手续费）**

```
借：其他货币资金—支付宝/平台账户    95,344
    销售费用—平台服务费              5,050
    财务费用—支付手续费                606
  贷：应收账款—平台/店铺            101,000
```

**④ 提现**

```
借：银行存款                        95,344
  贷：其他货币资金—支付宝/平台账户    95,344
```

**⑤ 快递费**

```
借：销售费用—快递费                  8,000
  贷：银行存款                         8,000
```

**⑥ 投流费**

```
借：销售费用—广告宣传费              10,000
  贷：银行存款                        10,000
```

**⑦ 达人佣金（个人，劳务报酬预扣个税）**

```
借：销售费用—达人佣金                 3,000
  贷：银行存款                         2,560
      应交税费—应交个人所得税            440
```

> 预扣计算：劳务报酬每次收入不超过 4,000 元的，减除费用 800 元，余额为预扣预缴应纳税所得额，按 20% 预扣率。即 (3,000−800)×20% = **440 元**。年度终了由达人并入综合所得汇算。

**⑧ 季度末，若符合小规模季度 30 万免征**

```
借：应交税费—应交增值税（减免税款）    1,000
  贷：其他收益（新准则）/ 营业外收入（小企业） 1,000
```

> 依据：财会〔2016〕22 号《增值税会计处理规定》——达到免征增值税条件时，将有关应交增值税转入当期损益。若该笔收入开具了增值税专用发票，则**不能免征**，不能做这笔转入。

### 2.2 自营总额法（一般纳税人，13%）

**场景**：含税售价 113 元/件，1,000 件，含税 113,000 元；不含税 100,000 元，销项 13,000 元；成本 50,000 元（不含税），进项 6,500 元；平台佣金 6,360 元（含税，6%），进项 360 元；支付手续费 636 元（含税，6%），进项 36 元；快递 8,720 元（含税，9%），进项 720 元；投流 10,600 元（含税，6%），进项 600 元。

**① 采购入库**

```
借：库存商品                        50,000
    应交税费—应交增值税（进项税额）  6,500
  贷：银行存款                        56,500
```

**② 发货确认收入**

```
借：应收账款—平台/店铺            113,000
  贷：主营业务收入                  100,000
      应交税费—应交增值税（销项税额）13,000
```

**③ 结转成本**

```
借：主营业务成本                    50,000
  贷：库存商品                        50,000
```

**④ 平台结算**

```
借：其他货币资金—支付宝/平台账户   106,004
    销售费用—平台服务费              6,000
    应交税费—应交增值税（进项税额）    360
    财务费用—支付手续费                600
    应交税费—应交增值税（进项税额）     36
  贷：应收账款—平台/店铺            113,000
```

**⑤ 快递费**

```
借：销售费用—快递费                  8,000
    应交税费—应交增值税（进项税额）    720
  贷：银行存款                         8,720
```

**⑥ 投流费**

```
借：销售费用—广告宣传费              10,000
    应交税费—应交增值税（进项税额）    600
  贷：银行存款                        10,600
```

> 一般纳税人取得平台 6% 专票、快递 9%/6% 专票、包材 13% 专票，均可抵扣；小规模只能取得普票，全额计入费用。**同样的费用，一般纳税人的实际成本比小规模低**，这是身份选择时要算进去的。

### 2.3 净额法（代销/分销）

**场景**：商家代销，商品含税售价 113,000 元，商家收 10% 佣金 11,300 元（含税），开具 6% 经纪代理服务发票。

```
借：应收账款—平台/委托方            11,300
  贷：主营业务收入（或其他业务收入） 10,660.38
      应交税费—应交增值税（销项税额）   639.62
```

若商家是小规模：

```
借：应收账款—平台/委托方            11,300
  贷：主营业务收入                   11,188.12
      应交税费—应交增值税               111.88
```

> 净额法下，商品本身不经过商家的存货和成本；如果商家先买断再卖，就不能用净额法。

### 2.4 退货的会计处理

#### A. 新准则：预计退货负债 + 应收退货成本

**销售时**（原销售 100,000 元，成本 50,000 元，估计退货率 10%）：

```
借：主营业务收入                    10,000
  贷：预计负债—应付退货款            10,000

借：应收退货成本                     5,000
  贷：主营业务成本                     5,000
```

> 口径说明：上式按**不含税**售价计提。若按含税口径计提，需把增值税一并计入预计负债，实际退货时冲减；两种口径不要混用。应收退货成本列报为“其他流动资产”，预计负债列报为“其他流动负债/预计负债”。

**实际退货 8%（8,000 元收入，4,000 元成本）**：

```
借：预计负债—应付退货款              8,000
    应交税费—应交增值税（销项税额）      80
  贷：银行存款                         8,080

借：库存商品                         4,000
  贷：应收退货成本                     4,000
```

**期末重估**：若实际退货率低于原估计，把多提的 2,000 元负债和 1,000 元成本转回：

```
借：预计负债—应付退货款              2,000
  贷：主营业务收入                     2,000

借：主营业务成本                     1,000
  贷：应收退货成本                     1,000
```

**实际退货 12%（超过原估计 10%）**：

```
借：预计负债—应付退货款             10,000
    主营业务收入                     2,000
    应交税费—应交增值税（销项税额）     120
  贷：银行存款                        12,120

借：库存商品                         6,000
  贷：应收退货成本                     5,000
      主营业务成本                     1,000
```

#### B. 小企业会计准则：不预估，实际退货冲减当期

小企业会计准则**不对销售退货确认预计负债、不确认应收退货成本**（简化处理）。销售时全额确认收入、结转成本；实际退货时：

```
借：主营业务收入                     8,000（红字）
    应交税费—应交增值税                 80（红字）
  贷：银行存款                         8,080

借：库存商品                         4,000
  贷：主营业务成本                     4,000
```

> 跨年退货：小企业通常冲减退货发生当期，不追溯调整；若金额重大且属于资产负债表日后事项，按准则相关章节处理，实务建议咨询税务师。税务上，增值税开红字发票/红字信息表冲减当期销项；企业所得税按实际退货调整当期收入/成本。

#### C. 退货率怎么估

- 用**滚动 12 个月**同品类、同渠道、同价格带的退货率；
- 大促后（双 11、618）退货率显著高于日常，按月拆分；
- 新店/新品没有历史数据，用行业基准（女装电商 50%–60%，直播 80% 左右，见第 7 节）并加保守缓冲；
- 期末必须重估，不能年初定一个 10% 用一年。

### 2.5 优惠券、满减、平台补贴

| 类型 | 谁承担 | 会计处理 | 增值税 | 备注 |
|---|---|---|---|---|
| 商家满减/优惠券 | 商家 | 按**净额**确认收入 | 按折扣后金额 | 商业折扣，同一发票注明 |
| 平台优惠券 | 平台 | 全额确认收入，或补贴计其他收益 | 与销量挂钩可能属价外费用 | 见下 |
| 达人专属券 | 达人/商家 | 按实际承担方 | 同上 | 合同要写明 |
| 平台返点/返利 | 平台 | 冲减销售费用/主营业务成本 | 平台开红字或 6% 发票 | 与销售/采购挂钩 |
| 平台补贴 | 平台 | 其他收益/冲减销售费用 | 可能并入销售额 | 争议点 |

**商家承担满减（满 101 减 10.1，实收 90.9）**：

```
借：应收账款—平台                  90,900
  贷：主营业务收入                  90,000
      应交税费—应交增值税              900
```

> 不是“收入 100,000 + 销售费用 10,000”。商家承担的折扣是**商业折扣**，直接冲减收入；增值税按折扣后金额计算（同一张发票上注明折扣额）。

**平台承担补贴（平台券 10,000，消费者付 91,000，平台补 10,000，商家共收 101,000）**：

保守做法（与销售直接挂钩，并入销售额）：

```
借：应收账款—平台                 101,000
  贷：主营业务收入                 100,000
      应交税费—应交增值税             1,000
```

替代做法（平台补贴属于独立营销服务，能取得平台 6% 发票）：

```
借：银行存款                       10,000
  贷：其他收益                       10,000
（若冲减费用，则贷记“销售费用—平台服务费”，或红字借记该科目；消费者支付的 91,000 按正常销售确认，分录略）
```

> **风险**：平台补贴如果按销量/销售额计算，税务机关可能认定为“价外费用”，要求并入销售额缴增值税。两种做法的差额就是 10,000÷1.01×1% ≈ 99 元（小规模）或 10,000÷1.13×13% ≈ 1,150 元（一般纳税人）。金额大时，建议与主管税务机关确认，不要自己拍。

**平台返点**：

```
借：银行存款                        5,000
  贷：销售费用—平台服务费            5,000
（或红字借记“销售费用—平台服务费”）
```

或冲减主营业务成本（若返点与采购量挂钩）。取得平台红字发票或 6% 服务费发票，避免“无票冲减”。

### 2.6 预售、定金、礼品卡

**收款时**：

```
借：银行存款                        20,000
  贷：合同负债—预收货款              20,000
```

**发货/签收确认收入**（含税 20,000，小规模 1%）：

```
借：合同负债—预收货款              20,000
  贷：主营业务收入                   19,801.98
      应交税费—应交增值税               198.02
```

> 小企业可以简化按含税记合同负债，确认收入时再价税分离；但一旦选定口径，不要跨期混用。

**定金不退**：买方违约没收定金，属于与销售相关的违约金，通常并入销售额缴增值税；会计上可冲减合同负债、确认收入/营业外收入，按合同实质判断。

**礼品卡/储值**：售卡时记合同负债；消费时确认收入；过期未消费的余额转营业外收入，但增值税/所得税存在“是否已发生应税行为”的判断，金额大时咨询税务机关。

### 3.1 科目表

| 科目 | 用途 | 关键提示 |

| 其他货币资金—支付宝/微信/平台账户 | 平台待结算、待提现余额 | 不要和银行存款混；按平台设明细 |
| 应收账款—平台/店铺 | 已确认收入、平台未结算 | 按平台、店铺、账期设明细 |

### 3.2 平台佣金/技术服务费

**小规模**：

```
借：销售费用—平台服务费              5,050
  贷：其他货币资金—支付宝/平台账户    5,050
```

**一般纳税人**：

```
借：销售费用—平台服务费              6,000
    应交税费—应交增值税（进项税额）    360
  贷：其他货币资金—支付宝/平台账户    6,360
```

**发票**：平台通常开“信息技术服务*技术服务费/平台服务费”，税率 6%。若发票品名是“佣金”或“经纪代理服务”，可能触发 5% 手续费及佣金限额（见 5.7）。**合同、发票、账单三者的品名要一致**。

> 若平台直接从结算款中扣佣金，贷记“应收账款—平台”；已经通过结算单扣减的，不要重复贷记“其他货币资金”。

### 3.3 支付手续费

```
借：财务费用—支付手续费                606
  贷：其他货币资金—支付宝/平台账户      606
```

- 费率通常 0.38%–0.6%，以签约费率为准；
- 一般纳税人取得 6% 专票可抵扣；
- 平台“提现费”“通道费”也记这里，不要记销售费用。

### 3.4 快递费、包材、仓储

**销售快递费**：

```
借：销售费用—快递费                  8,000
    应交税费—应交增值税（进项税额）    720   （一般纳税人，9% 运输）
  贷：银行存款                         8,720
```

**采购运费**（面料/成衣入库前）：

```
借：库存商品                        1,000
    应交税费—应交增值税（进项税额）     90
  贷：银行存款                         1,090
```

> 采购运费计入存货成本（《企业会计准则第 1 号——存货》第六条）；销售运费计入销售费用。不要把所有运费都塞进“销售费用”，否则毛利率会失真。

**包材**：

```
借：销售费用—包装费                  2,000
    应交税费—应交增值税（进项税额）    260   （一般纳税人，13%）
  贷：银行存款                         2,260
```

**仓储费**：

```
借：销售费用—仓储费                  3,000
    应交税费—应交增值税（进项税额）    180   （一般纳税人，6%）
  贷：银行存款                         3,180
```

**退换货物流**：记“销售费用—退换货损失”；如果退货量大，单独设明细，方便算履约成本占比。

### 3.5 达人佣金、坑位费

**坑位费（预付）**：

```
借：预付账款—达人/机构                21,200
  贷：银行存款                        21,200
```

**直播完成，结转费用**：

```
借：销售费用—坑位费                  20,000
    应交税费—应交增值税（进项税额）    1,200   （机构开 6% 专票）
  贷：预付账款—达人/机构              21,200
```

**按成交付佣金（个人达人，含税 3,000，代扣 440）**：

```
借：销售费用—达人佣金                 3,000
  贷：银行存款                         2,560
      应交税费—应交个人所得税            440
```

> 个人达人不能开专票，一般也不能抵进项；如果对方去税务局代开普票，企业取得普票，仍不能抵进项（小规模更不能）。机构/MCN 开 6% 专票的，可以抵扣。

### 3.6 投流费（直通车、千川、磁力金牛等）

**充值**：

```
借：预付账款—平台推广                50,000
  贷：银行存款                        50,000
```

**消耗**：

```
借：销售费用—广告宣传费              10,000
    应交税费—应交增值税（进项税额）    600   （6% 专票）
  贷：预付账款—平台推广              10,600
```

> 充值不能直接进费用，必须按消耗确认；月末未消耗余额留在预付账款。投流费通常按“广告费和业务宣传费”15% 限额扣除（见 5.7）。

### 3.7 保证金

**支付**：

```
借：其他应收款—平台保证金            20,000
  贷：银行存款                        20,000
```

**退回**：反向分录。

**无法收回**（平台关店、违规扣划）：

```
借：营业外支出—保证金损失            20,000
  贷：其他应收款—平台保证金            20,000
```

> 小企业不计提坏账准备；新准则按预期信用损失计提。税务上，无法收回的保证金作为资产损失，需按 2011 年第 25 号、2018 年第 15 号留存资料（合同、扣划通知、平台闭店证明、付款凭证等）。

### 3.8 退货入库、残次品

**退货入库**：

```
借：库存商品                         4,000
  贷：主营业务成本                     4,000
```

（新准则下，若已记“应收退货成本”，则冲减该科目。）

**残次品变卖**：

```
借：银行存款                         1,000
  贷：其他业务收入                       990.10
      应交税费—应交增值税                  9.90   （小规模 1%）

借：其他业务成本                       800
  贷：库存商品                           800
```

**报废（管理不善）**：

```
借：待处理财产损溢                   1,130
  贷：库存商品                         1,000
      应交税费—应交增值税（进项税额转出） 130

借：营业外支出                       1,130
  贷：待处理财产损溢                   1,130
```

> 管理不善造成的非正常损失，进项税不得抵扣（《增值税法》第二十二条第三项、实施条例第十九条）。自然灾害等不可抗力不属于“非正常损失”，进项可抵扣，但所得税损失仍需资料。

### 3.9 刷单（合规拒绝，但要知道怎么处理）

- **会计**：刷单没有真实商品转移，**不得确认收入**；已经确认的，红字冲回。
- **增值税**：刷单若开票，属于虚开；若不开票但平台报送了收入，申报不实。
- **所得税**：刷单产生的空包费、刷手佣金、平台佣金，属于违法支出/与经营无关，**不得税前扣除**。
- **法律**：《反不正当竞争法》第八条、第二十条；《税收征收管理法》第六十三条；《刑法》第二百零五条（虚开增值税专用发票罪）。

**如果历史上有刷单**：停止 → 清理台账 → 区分真实/虚假订单 → 自查补税（增值税、所得税、个税）→ 保留真实交易证据 → 不要用“买票”去平账。

## 4. 存货核算

### 4.1 移动加权平均 vs 先进先出

| 方法 | 适用 | 优点 | 缺点 |
|---|---|---|---|
| 移动加权平均 | SKU 多、补货频繁、仓库混放 | 每次入库重算，接近实际；系统易实现 | 单价随采购波动；月末才能准 |
| 先进先出（FIFO） | 批次清晰、季末清仓、保质期/色号敏感 | 结存接近近期市价 | 手工核算量大；退货批次难匹配 |
| 个别计价 | 高单价、限量款、联名款 | 最精确 | 服装 SKU 多时不可行 |

**服装电商实务**：默认**移动加权平均**；季末清仓、尾货打包可按批次/SKU 个别计价；不要一套账里混用多种方法。

> 如果 SKU 多、手工账，可用**月末一次加权平均**（全月入库一次加权，月末算一次单价）；系统账建议移动加权平均。两者同属加权平均法，但单价计算频率不同，选定后不要混用。

**移动加权平均公式**：

```
新单位成本 = (原库存金额 + 本次入库金额) ÷ (原库存数量 + 本次入库数量)
```

**示例**：期初 100 件×50 元=5,000 元；入库 200 件×60 元=12,000 元；加权单位成本 = 17,000÷300 = **56.67 元**；销售 150 件，成本 = 150×56.67 = **8,500 元**；结存 150 件×56.67 ≈ 8,500 元。

**FIFO 对比**：销售 150 件 = 100×50 + 50×60 = **8,000 元**；结存 150×60 = 9,000 元。两种方法当期成本差 500 元，毛利率差约 0.5 个百分点（按 10 万收入计）。方法一经选定，**不得随意变更**。

### 4.2 入库成本构成

```
存货成本 = 购买价款 + 相关税费 + 运输费 + 装卸费 + 保险费 + 其他可归属于存货采购成本的费用
```

- 可抵扣的增值税进项**不计入**成本；小规模纳税人取得的进项计入成本。
- 采购运费、质检费、挑拣费计入成本；销售快递费计入销售费用。
- 委外加工：面料成本 + 加工费 + 往返运费；加工费取得 13% 专票可抵。
- 样品/赠品：用于推广的样品计入销售费用；无偿赠送需视同销售（增值税），除非随货销售且不单独计价。

### 4.3 存货跌价准备（新准则）

**可变现净值（NRV）**：

```
NRV = 估计售价 − 估计销售费用 − 相关税费
```

**示例**：成本 100 元，估计售价 80 元，销售费用 10 元，税费 2 元 → NRV = 68 元，计提跌价 32 元。

```
借：资产减值损失                     32
  贷：存货跌价准备                     32
```

**转回**：若 NRV 回升到 90 元，可转回 22 元（转回后账面价值不超过原成本 100 元）。

```
借：存货跌价准备                     22
  贷：资产减值损失                     22
```

**小企业会计准则**：不计提存货跌价准备，按成本计量；实际发生毁损、报废、盘亏时，直接计入营业外支出/管理费用。

**税务**：计提的跌价准备属于“未经核定的准备金支出”，**不得税前扣除**（《企业所得税法》第十条），汇算清缴调增；实际处置/报废时，按 2011 年第 25 号、2018 年第 15 号确认资产损失。

### 4.4 季末清仓、打折、买赠

**打折销售**（原价 101 元，清仓 60 元，成本 50 元，小规模 1%）：

```
借：银行存款                         60
  贷：主营业务收入                     59.41
      应交税费—应交增值税                0.59

借：主营业务成本                     50
  贷：库存商品                         50
```

> 增值税按折扣后 60 元计算；若在同一张发票上注明原价和折扣额，可按折扣后金额计税。不要“按原价开票、另开红字”，容易引发比对异常。

**买一赠一**：

- 增值税：无偿赠送视同销售，但“买一赠一”属于捆绑销售，实务可按公允价值分摊，不单独视同销售；各地口径有差异，金额大时确认。
- 企业所得税：按公允价值比例分摊确认收入（国税函〔2008〕875 号）。
- 会计：按分摊后的金额确认收入，赠品成本计入主营业务成本。

**清仓价低于成本**：正常销售，损失体现在毛利；不需要特别税务处理。但若价格明显偏低且无正当理由，税务机关可按《增值税法》第二十条核定销售额。保留清仓方案、折扣审批、同品类比价记录。

**报废/销毁**：进项转出（管理不善）；所得税资产损失需留存资料（报废清单、审批、照片、销毁记录）。

### 4.5 盘亏、盘盈

**盘亏（管理不善，成本 10,000，进项 1,300）**：

```
借：待处理财产损溢                  11,300
  贷：库存商品                        10,000
      应交税费—应交增值税（进项税额转出）1,300

借：管理费用                        11,300
  贷：待处理财产损溢                  11,300
```

- 若由责任人赔偿：借“其他应收款”，差额记管理费用/营业外支出。
- 若自然灾害：进项可抵扣，损失记营业外支出；所得税按资产损失资料扣除。
- 小企业会计准则下同样通过“待处理财产损溢”，批准后转损益。

**盘盈**：

```
借：库存商品                        10,000
  贷：待处理财产损溢                  10,000

借：待处理财产损溢                  10,000
  贷：管理费用                        10,000（红字冲减）
```

> 盘盈通常冲减管理费用；金额大的，作为前期差错更正（新准则）或调整当期（小企业）。

## 5. 税务要点

### 5.1 小规模 vs 一般纳税人

| 维度 | 小规模 | 一般纳税人 |
|---|---|---|
| 标准 | 年应征增值税销售额 ≤ 500 万（《增值税法》第九条） | 超过 500 万，或自愿登记 |
| 税率/征收率 | 3% 征收率，现行减按 **1%** | 货物 **13%**；服务 6%/9% |
| 进项抵扣 | **不能** | 可以（专票/海关缴款书等） |
| 季度 30 万 | **免征**（开专票部分不免） | 不适用 |
| 客户 | 个人消费者为主 | 大客户/平台要求专票 |
| 申报 | 简单，按季 | 复杂，按月/季，需认证/勾选 |
| 账务 | 价税分离简单 | 需设销项/进项/转出明细 |

**2026 年重要变化**：

- 《增值税法》自 2026-01-01 施行；小规模标准仍为 500 万（第九条），货物税率 13%（第十条），征收率 3%（第十一条）。
- 超标登记：年应征增值税销售额按**连续不超过 12 个月或四个季度**累计（含免税销售额）；超过 500 万的，应在超过标准**次月申报纳税期限内**办理登记，一般纳税人生效之日为**超过标准当期的 1 日**（2026 年第 2 号第六条），不是“次月生效”，要追溯当期。未按期办理的，自期限结束后 5 个工作日起按一般纳税人管理。
- 登记为一般纳税人后，**不得转回**小规模（实施条例第三十六条）。
- 小规模优惠：2026 年第 10 号公告，起征点月 10 万/季 30 万，3% 减按 1%，执行至 2027-12-31。**注意**：2023 年第 19 号自 2026-01-01 起已被 2026 年第 10 号衔接替代，引用时用新文号。

**身份选择测算（示意，含税销售 100 万，采购 60 万，费用 10 万，人工房租 10 万）**：

| 项目 | 小规模（1%，采购普票） | 一般纳税人（13%，采购专票） | 一般纳税人（采购无票） |
|---|---:|---:|---:|
| 含税收入 | 1,000,000 | 1,000,000 | 1,000,000 |
| 不含税收入 | 990,099 | 884,956 | 884,956 |
| 销项税/应纳增值税 | 9,901 | 115,044 | 115,044 |
| 进项税 | 0 | 74,687 | 5,660 |
| 应纳增值税 | 9,901 | 40,357 | 109,384 |
| 附加税（减半） | 594 | 2,421 | 6,563 |
| 成本 | 600,000 | 530,973 | 600,000 |
| 费用 | 100,000 | 94,340 | 94,340 |
| 人工/房租 | 100,000 | 100,000 | 100,000 |
| 利润 | 190,099 | 159,643 | 90,616 |
| 所得税（5%） | 9,475 | 7,861 | 34,531（按应纳税所得额 690,616 计，成本不得扣） |
| 净利 | 180,030 | 149,361 | **−59,862** |

> 第三列“所得税”不是会计利润 90,616 的 5%，而是按“收入 − 可扣除费用 − 人工”后的应纳税所得额 690,616 计算（无票成本 600,000 全额调增）；“净利”按会计利润减增值税、附加税、所得税后倒算，用于展示现金流后果。

> 假设季度销售额超过 30 万元、不享受小规模免征；若季度 ≤30 万，小规模增值税与附加税为 0，净利更高。表中未考虑库存跌价、退货损失、研发加计等。

> 结论：服装电商毛利率高、进项少，**小规模 1% 通常更省税**；但年销售接近/超过 500 万、大客户要专票、平台要求一般纳税人时，只能转。**不要为了保留小规模而拆主体**（见 5.10）。上表“无票”是极端示意，用来说明无票采购的杀伤力，不是建议。

### 5.2 小规模纳税人优惠

**依据**：《财政部 税务总局关于增值税法施行后增值税优惠政策衔接事项的公告》（2026 年第 10 号）。

- 月销售额 10 万元以下（含）免征；按季 30 万元以下（含）免征；按次（日）1,000 元起征点。
- 适用 3% 征收率的应税销售收入，减按 **1%** 征收；预缴项目减按 1% 预征。
- 执行至 **2027-12-31**。

**计算**：

```
不含税销售额 = 含税销售额 ÷ (1 + 1%)   （若放弃减税按 3% 开票，则除以 1.03）
应纳增值税 = 不含税销售额 × 1%
```

**四个易错点**：

1. 30 万是**季度合计不含税销售额**，不是单月；超过 30 万，**全额计税**，不是只对超出部分计税。
2. 开增值税专用发票的部分**不能免税**，要单独按 1%（或放弃减税按 3%）缴税。小规模开专票通常按 1% 税率栏；若选择放弃减税，可按 3% 开具，具体以申报系统为准。
3. 未开票收入、平台补贴（若属价外费用）、视同销售都要计入销售额。
4. 免税时，附加税也免；缴纳增值税时，城建税 7%/5%/1% + 教育费附加 3% + 地方教育附加 2%，小规模/小微**减半**（2023 年第 12 号，至 2027-12-31）。

**免税的会计处理**：平时按 1% 计提，季末符合免税条件时转入当期损益（财会〔2016〕22 号）：

```
借：应交税费—应交增值税（减免税款）
  贷：其他收益（新准则）/ 营业外收入（小企业）
```

> 小企业也可在确认收入时全额计入主营业务收入、不分离税额（简化做法），但一旦选定口径，全年保持一致；本文用“先按 1% 计提、季末转损益”的口径，便于与申报表核对。

### 5.3 一般纳税人

- 销项 = 不含税销售额 × 13%（服装货物）。
- 进项：面料/成衣 13%、平台服务 6%、快递 9%/6%、包材 13%、仓储 6%、广告 6%、不动产租赁 9% 等，凭专票/海关缴款书/完税凭证抵扣。
- 进项转出：用于简易计税、免税、集体福利/个人消费、非正常损失（管理不善、违法没收销毁）的进项，不得抵扣。
- 月末结转：`应交税费—应交增值税（转出未交增值税）` → `应交税费—未交增值税`。
- 留抵：当期进项大于销项，可结转下期或按规定申请留抵退税（需符合条件）。

**无票采购对一般纳税人是双杀**：进项不能抵 → 增值税多缴；成本不能税前扣除 → 所得税多缴。见 5.1 表第三列。

### 5.4 无票采购：风险与合规路径

**风险链条**：

```
供应商不开票
  → 增值税：无进项（一般纳税人）或少抵（小规模不能抵）
  → 所得税：成本不得税前扣除（28 号公告）
  → 利润虚高 → 多缴 5%/25% 所得税
  → 若买票平账 → 虚开增值税专用发票罪（刑法 205 条）
  → 平台报送（810 号令）+ 银行流水 + 物流数据 → 比对异常
```

**量化**：无票成本 100 万，小微企业 5% → 多缴所得税 5 万；一般企业 25% → 25 万；再加滞纳金（日万分之五，年化约 18.25%）和 0.5–5 倍罚款。**买票的刑事风险远高于省下的税**。

**合规路径**（按优先级）：

| 路径 | 适用 | 成本 | 风险/注意 |
|---|---|---|---|
| 供应商注册个体户/小规模/一般纳税人，自行开票 | 长期合作工厂、档口 | 供应商税负上升，可能加价 2%–8% | 最正规；合同约定发票条款 |
| 自然人代开（税务局代开普票） | 零星、小额、临时采购 | 综合税负约 3%–8%（各地不同） | 需合同、身份证、付款；不能长期大额 |
| 供应链公司/贸易商采购 | 自身无票、又需要 13% 专票 | 加价 3%–10% | 确保货物流、资金流、发票流一致 |
| 委托加工 | 自己买面料、作坊加工 | 面料 13% + 加工费 13% | 分别取得发票；委托加工合同 |
| 收购档口/作坊（股权） | 长期依赖的独家供应商 | 尽调/整合成本 | 承接历史税务风险，需尽调 |
| 灵活用工平台 | 真实灵活用工（临时客服、仓配） | 服务费 3%–8% | 必须有真实业务，不能“买票” |
| 个体户核定征收 | 小规模、账不全 | 综合税负低 | 需实质经营；虚开仍违法 |

**28 号公告的关键条款**（国家税务总局公告 2018 年第 28 号）：

- 第九条：境内应税项目，对方为已税务登记的增值税纳税人，**以发票为税前扣除凭证**；对方为无需登记的单位或从事**小额零星经营**的个人，以代开发票或**收款凭证 + 内部凭证**为凭证。小额零星的判断标准是个人销售额不超过增值税起征点——2026 年起按次（日）**1,000 元**。
- 第十三条：应取得而未取得发票的，若支出真实且已发生，应在**当年度汇算清缴期结束前**要求对方补开、换开；补开后可扣除。
- 第十四条：因对方**注销、撤销、吊销、非正常户**等特殊原因无法补开的，可凭 6 项资料证明真实性后扣除：①无法补开原因的证明；②合同/协议；③**非现金支付**凭证；④货物运输证明；⑤入库/出库内部凭证；⑥会计核算记录。其中**①②③为必备**。
- 第十五条：汇算清缴结束后被税务机关告知的，应在**60 日内**补开/换开或提供第十四条资料。
- 第十六条：逾期未补开、又不符合第十四条的，**不得扣除**。
- 第十七条：以前年度未扣除的，以后年度取得合规凭证可**追补至发生年度**扣除，追补年限不超过 **5 年**。

**实操清单**：

1. 供应商准入：营业执照、纳税人资格、开票能力、经营范围；避免“三无”作坊。
2. 合同：写明含税/不含税、税率、发票类型、开票时间、违约责任。
3. 付款：**公户转账**，不付老板私卡；付款方与合同/发票一致。
4. 单据：采购订单、入库单、质检单、物流单、对账单，按月归档。
5. 发票台账：进项发票认证/勾选、普票入账、无票清单逐月跟踪。
6. 汇算清缴前：把无票清单拉出来，能补的补，不能补的按第十四条准备资料。

### 5.5 平台服务费发票

- 平台通常开 **6%** 增值税专用发票/普通发票，品名“信息技术服务*技术服务费”“平台服务费”“推广费”。
- 小规模取得普票，不能抵进项，全额计入销售费用；一般纳税人取得专票，可抵 6%。
- 平台佣金/技术服务费/推广费要**分开明细**，因为税务限额不同（佣金 5% vs 广告费 15%）。
- 平台返点/补贴：要求平台开红字发票或 6% 服务费发票，避免“无票冲减费用”。
- 发票备注栏：平台订单号/结算单号，方便对账。

### 5.6 直播达人佣金的个税

| 达人身份 | 企业支付性质 | 企业义务 | 发票 |
|---|---|---|---|
| 自然人 | 劳务报酬 | **预扣预缴个税**（20%–40%） | 自然人代开普票或收款凭证（小额） |
| 个体工商户 | 经营所得 | 不代扣（个体户自行申报） | 个体户开票（1%/3%/6%） |
| 个人独资企业/公司 | 经营所得/企业所得税 | 不代扣 | 开票（6%/13% 视服务） |
| MCN 机构 | 服务费 | 不代扣（MCN 负责） | MCN 开 6% 专票 |
| 灵活用工平台 | 服务费/劳务 | 平台代征/代扣 | 平台开票 |

**劳务报酬预扣**（国家税务总局公告 2018 年第 61 号）：

- 每次收入 ≤ 4,000 元：减除 800 元；> 4,000 元：减除 20%。
- 预扣率：应纳税所得额 ≤ 2 万 → 20%；2–5 万 → 30%（速算扣除 2,000）；> 5 万 → 40%（速算扣除 7,000）。
- 年度终了并入综合所得汇算，多退少补。

**未代扣的后果**：《税收征收管理法》第六十九条，处应扣未扣税款 **50%–3 倍**罚款，并责令补扣。

**风险提示**：把实质为劳务报酬的达人收入，强行注册个体户按“经营所得”核定征收，可能被认定为转换收入性质、偷税。合同、资金、服务实质要一致。

### 5.7 广告费 15% 限额

**依据**：《企业所得税法实施条例》第四十四条——符合条件的广告费和业务宣传费，不超过当年销售（营业）收入 **15%** 的部分准予扣除；超过部分准予在以后纳税年度**结转扣除**。

- 服装不属于 30% 限额行业（化妆品制造或销售、医药制造、饮料制造不含酒类），所以是 **15%**。
- “销售（营业）收入”包括主营业务收入、其他业务收入、视同销售收入，**不含营业外收入**。
- 投流费（直通车、千川、磁力金牛）、达人坑位费、品牌广告、平台推广费，通常归入“广告费和业务宣传费”。
- **达人佣金**可能被认定为“手续费及佣金”（5% 限额）或“广告费”（15% 限额），取决于合同和业务实质。这是服装电商最大的税务争议点之一，见下。

**示例**：营业收入 500 万，广告费 100 万 → 限额 75 万，调增 25 万，结转以后年度。若次年营业收入 600 万，限额 90 万；次年实际发生广告费 80 万，则还可扣结转的 10 万（80+10=90），剩余 15 万继续结转。

**佣金 5% 限额**（财税〔2009〕29 号）：

- 一般企业：按与具有合法经营资格的中介服务机构或个人签订的服务协议/合同确认的收入金额的 **5%** 计算限额；超过部分不得扣除（不是结转）。
- 实务中，税务机关多按对应销售/服务收入计算 5% 限额；具体基数是“服务协议金额”还是“销售额”，各地口径有差异，需与主管税务机关确认。
- 服装电商的达人佣金率常见 10%–30%，若被定性为“佣金”，超 5% 部分要调增，冲击很大。
- 若合同定性为“广告发布/营销服务”，发票开“广告服务/信息服务”，可按 15% 广宣费限额，通常更宽松。
- **建议**：合同、发票、结算单、业务实质四者一致；不要一边签“佣金协议”、一边开“广告费”发票。金额大时提前与主管税务机关沟通。

### 5.8 业务招待费

**依据**：《企业所得税法实施条例》第四十三条——按发生额 **60%** 扣除，但最高不得超过当年销售（营业）收入的 **5‰**。

**示例**：营业收入 500 万，业务招待费 10 万 → 60% = 6 万；5‰ = 2.5 万；可扣 **2.5 万**，调增 **7.5 万**。

**区分**：

- 请客户吃饭、送客户礼品、客户旅游 → 业务招待费；
- 展会、线上推广、品牌广告、达人种草 → 广告费和业务宣传费；
- 员工团建/福利 → 职工福利费（14% 限额）；
- 送给个人的礼品，还可能涉及个税（偶然所得 20%）和增值税视同销售，金额大时要一并考虑。

### 5.9 刷单虚增收入的风险

| 风险 | 后果 |
|---|---|
| 会计 | 不得确认收入；已确认需红字冲回；财务报表失真 |
| 增值税 | 开票即虚开；不申报则平台报送数据与申报差异 |
| 企业所得税 | 刷单成本不得扣除；虚增收入多缴税；隐瞒收入构成偷税 |
| 反不正当竞争 | 第八条虚假宣传，第二十条罚款 20 万–100 万，情节严重 100 万–200 万，可吊销营业执照 |
| 刑事 | 虚开增值税专用发票罪（刑法 205 条），最高无期徒刑 |
| 平台 | 扣分、降权、封店、保证金扣划 |

**平台报送**：《互联网平台企业涉税信息报送规定》（国令第 810 号，2025-06-20 公布施行）要求平台于**季度终了的次月内**报送平台内经营者和从业人员的身份信息、上季度收入信息。2025 年 Q3 起首次报送，税务端已具备“平台数据 vs 申报数据”比对能力。

**自查顺序**：停止刷单 → 导出平台订单/退款/物流 → 标记异常订单（同一地址/账号、空包、高退款）→ 区分真实收入 → 更正申报 → 补税/滞纳金 → 保留证据。**不要用买票、私卡、两套账去“消化”差异**。

### 5.10 跨平台、多主体经营

- **每个主体独立纳税人**：各自判断小规模/一般纳税人，各自 500 万标准，各自申报。
- **同一主体多店铺**：收入汇总，平台按主体（统一社会信用代码）报送，不是按店铺；不要以为“多开几个店就能分散收入”。
- **多主体拆分**：若人员、场地、资金、采购、客服混同，仅为享受小规模/小微优惠而拆分，可能被认定为“不具有合理商业目的”，税务机关可调整（《增值税法实施条例》第五十三条；《企业所得税法》第四十一条、第四十七条）。
- **关联交易**：主体之间调货、服务费、资金拆借，要**公允定价**、有合同、有发票、有资金流；否则面临纳税调整。
- **四流一致**：合同流、资金流、发票流、货物流（物流单/入库单）要能对上。
- **跨省仓库**：增值税一般在机构所在地申报；仓库本身通常不改变纳税地点，但若设立分支机构/固定经营场所并被认定为独立纳税主体，或涉及异地经营/社保/工商备案，需单独确认。

**建议架构**：主体数量与业务实质匹配；不要为税而拆；多主体用统一 ERP + 关联交易台账；每年做一次“主体功能与风险”复盘。

## 6. 内控与对账

### 6.1 三方对账：平台账单 vs 银行/支付宝流水 vs ERP/账

**数据源**：

1. 平台结算单：订单、退款、佣金、推广费、保证金、补贴、罚款、提现。
2. 支付宝/微信/银行流水：实际到账、提现、手续费。
3. ERP/进销存/财务账：收入、成本、费用、应收、库存。

**七步流程**：

1. **导出**上月平台账单（按结算周期，不是自然月）。
2. **核对订单**：订单号、金额、状态（已支付/已退款/已取消）。
3. **核对退款**：退款金额、退款时间、是否跨月、是否已冲减收入。
4. **核对扣费**：佣金、技术服务费、推广费、支付手续费、保证金、罚款。
5. **核对提现**：提现申请、到账、在途、手续费。
6. **编制余额调节表**：平台账户、支付宝、银行、ERP 应收四方余额。
7. **差异分析 + 账务调整**：逐笔说明，不能“轧差”了事。

**平台账户余额公式**：

```
期末余额 = 期初余额
         + 本期收款
         − 退款
         − 平台佣金/技术服务费
         − 推广费
         − 保证金（新增）
         − 提现
         + 平台补贴/返点
         ± 其他（罚款、赔付、跨期结算）
```

**示例**：期初 50,000；收款 1,000,000；退款 100,000；佣金 50,000；推广 80,000；保证金 20,000；提现 700,000；补贴 10,000 → 期末 **110,000**。若银行/支付宝显示 100,000，差 10,000，重点查“在途提现/未入账手续费/跨月结算”。

**常见差异类型**：

| 差异 | 原因 | 处理 |
|---|---|---|
| 在途结算 | 平台已扣款、银行未到账 | 记“其他货币资金—在途” |
| 跨月退款 | 12 月销售、1 月退款 | 12 月估退货或 1 月冲减，口径统一 |
| 手续费 | 平台/支付通道单独扣 | 补记财务费用 |
| 罚款/赔付 | 延迟发货、违规 | 记营业外支出/销售费用，索取凭证 |
| 重复结算 | 平台重复打款 | 挂“其他应付款”，退回 |
| 未提现 | 平台余额未转出 | 其他货币资金余额与平台一致 |
| 补贴/返点 | 未入账 | 补记其他收益/冲减费用 |

### 6.3 常见舞弊与差错

| 现象 | 识别信号 | 后果 | 对策 |
|---|---|---|---|
| 刷单 | 同一地址/账号、空包、退款率异常、凌晨集中下单 | 虚增收入/虚开/罚款 | 停止、自查、更正申报 |
| 私卡收款 | 平台绑定个人卡、个人码收款、银行流水与账单不符 | 隐匿收入、偷税、股东分红补税 | 全部公户；个人卡流水清理 |
| 重复确认收入 | 平台账单与 ERP 重复、跨月重复 | 多缴税/报表失真 | 订单号唯一匹配 |
| 退货未冲减 | 退货率高但收入未减、库存与退货不匹配 | 多缴税/虚增利润 | 退货台账、红字发票 |
| 佣金漏记 | 平台自动扣佣、账面费用偏低 | 少计费用、多缴税 | 结算单逐项核对 |
| 保证金未记 | 平台扣保证金记成费用 | 资产流失、费用虚增 | 其他应收款台账 |
| 平台补贴未记 | 补贴进私卡/未入账 | 隐匿收入 | 平台账单逐笔核对 |
| 虚列成本 | 买票、虚假运费/包材 | 虚开/偷税 | 四流一致、供应商准入 |
| 关联方占用 | 其他应收款长期挂账、老板借款 | 视同分红 20% 个税 | 年度清理、借款合同/利息 |

### 6.4 关键控制点

- **职责分离**：运营（订单/退款）与财务（对账/记账）分离；出纳不记账。
- **审批**：折扣、清仓、达人佣金、投流预算、退货退款，设金额阈值和审批人。
- **对账**：每月三方对账，差异逐笔说明；季度做一次“平台-银行-ERP”全量核对。
- **盘点**：每月抽盘 TOP SKU，季度全盘；盘盈盘亏查明原因。
- **发票**：进项发票台账、无票清单、红字发票审批；不得买票。
- **权限**：平台后台、支付宝、银行 U 盾分人保管；离职人员立即收回权限。
- **资金**：所有收款进公户；禁止私卡、个人码；老板借款签合同、计息、年度归还。

## 7. 关键财务指标（服装电商）

### 7.1 指标表

| 指标 | 公式 | 参考区间 | 来源/口径 |
|---|---|---|---|
| 毛利率 | （营业收入 − 营业成本）÷ 营业收入 × 100% | 品牌 50%–65%；白牌 30%–45%；直播 40%–60% | 经验值，按品类/定位差异大 |
| 退货率 | 退货金额 ÷ 支付 GMV × 100%（或退货订单÷成交订单） | 女装电商 50%–60%；直播渠道约 80% | 光明网/经济日报 2026-10-14 |
| 投流 ROAS | 投放带来的成交额 ÷ 投放费用 | 2–5；盈亏平衡 = 1÷毛利率 | 经验值 + 公式 |
| 库存周转天数 | 平均库存余额 ÷ 营业成本 × 365 | 上市公司 300–470 天；电商小企业 60–150 天 | 新浪财经 2026-05-22；经验值 |
| 动销率 | 有销售 SKU 数 ÷ 总 SKU 数 × 100% | 60%–80% | 经验值 |
| 售罄率 | 累计净销售件数 ÷ 累计可售货量 × 100% | 季末 70%–80%；APQC 样本中位数 68% | 第七在线 2026-09-03 |
| 客单价 | 营业收入 ÷ 订单数 | 卫衣/内衣 100–300 元 | 经验值 |
| 复购率 | 重复购买客户数 ÷ 总客户数 × 100% | 20%–40% | 经验值 |
| 履约成本占比 | （快递+仓储+包材+退换货）÷ 营业收入 × 100% | 10%–15% | 行业报告“10% 以上”；经验值 |
| 净利率 | 净利润 ÷ 营业收入 × 100% | 3%–10%；A 股服饰公司过半不足 7% | 经验值；媒体统计 |

> **用法**：先看退货率、毛利率、ROAS、库存周转四个“经营杠杆”，再看净利率。单月数字会被大促扭曲，至少看 12 个月趋势和同品类对比。

### 7.2 几个关键公式的展开

**盈亏平衡 ROAS**：

```
只考虑投流与毛利：ROAS* = 1 ÷ 毛利率
考虑履约与平台费：ROAS* = 1 ÷ (毛利率 − 履约成本率 − 平台费率)
```

示例：毛利率 50%，履约 12%，平台费 5% → ROAS* = 1÷(0.50−0.12−0.05) = **3.03**。投流 ROAS 低于 3.03，投流本身就在亏钱。

**库存周转天数**：

```
库存周转天数 = 平均库存余额 ÷ 营业成本 × 365
平均库存余额 = （期初库存 + 期末库存）÷ 2
```

示例：平均库存 100 万，年营业成本 600 万 → 60.8 天。服装季末库存会飙升，建议同时看“库龄结构”（0–30/31–90/91–180/180+ 天）。

**退货率对利润的杀伤**：

```
退货后的净毛利率 ≈ 毛利率 − 退货率 × (毛利率 + 退货处理成本率)
```

示例：毛利率 50%，退货率 60%，退货处理成本率 8% → 净毛利率 ≈ 50% − 60%×(50%+8%) = **15.2%**。这就是为什么女装直播“看着卖得多、实际不赚钱”。

**售罄率 vs 动销率**：

- 售罄率按**件数**，看“货卖掉了多少”；
- 动销率按**SKU**，看“多少款在动”；
- 一个款动销了但售罄率很低（卖了几件），另一个款售罄率高但断码——要结合看。

### 7.3 指标异常的诊断顺序

```
净利率下降
  ├─ 毛利率下降 → 采购价涨？折扣加深？退货率升？货品结构变差？
  ├─ 履约成本升 → 快递涨价？退换货多？仓储费高？包材浪费？
  ├─ 投流效率降 → ROAS 降？素材老化？人群变贵？平台流量成本升？
  ├─ 平台费率升 → 佣金/技术服务费涨？活动参与多？
  └─ 库存跌价 → 季末清仓折扣？库龄老化？SKU 过多？
```

## 9. 假设、口径与不确定项

**政策时效**：

- 本笔记写于 2026-10-24，适用 2026-2027 年。2027 年后小规模 1%、30 万免征、小微 5%、六税两费减半是否延续，以财政部/税务总局新公告为准。
- 2023 年第 19 号自 2026-01-01 起停止执行，由 2026 年第 10 号衔接；不要再引用 19 号作为现行依据。
- 地方口径（如平台补贴、达人佣金、无票采购、核定征收）差异较大，申报前必须与主管税务机关确认。

**会计政策选择**：

- 默认小企业会计准则；若企业实际执行企业会计准则，退货、跌价、坏账、递延所得税的分录不同，不能混用。
- 总额/净额、退货率估计、存货计价方法属于**会计估计/政策**，一经选定应保持一致，变更需披露。

**争议点（按风险排序）**：

1. **达人佣金定性**：5% 佣金限额 vs 15% 广告费限额，直接影响可扣除金额；合同/发票/实质要一致。
2. **平台补贴增值税**：与销量挂钩的补贴可能被认定为价外费用；独立营销服务则可能不征增值税。金额大时先沟通。
3. **一件代发总额/净额**：取决于谁控制商品、谁承担退货/存货风险；仅看“谁发货”不够。
4. **无票采购**：28 号公告第十四条只适用于对方注销/非正常户等特殊原因，不是“随便写个说明就能扣”。
5. **刷单历史**：自查补税的处理方式、是否定性为偷税，各地口径不同；建议由税务师协助。
6. **跨主体拆分**：是否具有合理商业目的，取决于人员、场地、资金、业务实质，不是“注册几个个体户”就安全。

**行业区间**：

- 退货率、毛利率、净利率、库存周转等区间来自公开报道/行业报告/经验值，样本偏差大（上市公司 vs 小微企业、品牌 vs 白牌、直播 vs 货架），只能做**方向性参考**，不能当考核硬指标。
- 平台费率（佣金/技术服务费/支付手续费）随时调整，以商家后台签约费率为准；本笔记不写死具体平台费率。

**未展开的事项**：

- 跨境电商/出口退税、进口面料关税、保税仓；
- 平台自营采销的复杂合同（返利、账扣、联合促销）；
- 股权激励、并购、集团合并报表；
- 税务稽查应对、行政复议/诉讼；
- 社保、公积金、劳动合同等用工合规（仅点到）。

## 10. 一页纸速查

**税率/征收率**：

| 场景 | 税率/征收率 |
|---|---|
| 服装货物销售（一般纳税人） | 13% |
| 小规模销售货物 | 3% 征收率，现行减按 1% |
| 平台技术服务/推广/经纪代理 | 6% |
| 快递收派 | 6%；运输 9% |
| 包材 | 13% |
| 仓储/不动产租赁 | 6%/9% |
| 附加税 | 城建 7%/5%/1% + 教育 3% + 地方教育 2%，小规模减半 |

**核心公式**：

```
不含税收入 = 含税收入 ÷ (1 + 税率或征收率)
应纳增值税（小规模）= 不含税销售额 × 1%
应纳增值税（一般）= 销项 − 进项（− 进项转出）
毛利率 = (收入 − 成本) ÷ 收入
退货率 = 退货金额 ÷ 支付GMV
ROAS = 投放成交额 ÷ 投放费用
盈亏平衡 ROAS = 1 ÷ 毛利率（或 1 ÷ (毛利率 − 履约率 − 平台费率)）
库存周转天数 = 平均库存 ÷ 营业成本 × 365
售罄率 = 净销售件数 ÷ 可售货量
履约成本占比 = (快递+仓储+包材+退换货) ÷ 收入
```

**做账顺序**：

```
订单/发货 → 确认收入（价税分离）→ 结转成本
→ 平台结算（佣金/手续费/补贴）→ 提现
→ 退货（冲收入/成本/库存）→ 月末对账 → 计提费用/税金 → 报表
```

**合规红线**：

```
不刷单、不买票、不私卡收款、不做两套账、
不把劳务报酬硬转个体户、不为省税拆主体。
```
