## 0. 结论速览

| 场景 | 推荐组合 | 说明 |
|---|---|---|
| 个人 / 10 人以内小团队记账、要可编程、要版本管理 | **beancount + fava**（或 ledger / hledger） | 纯文本复式记账，账本可进 Git，报表可脚本化，适合 agent 直接读写 |
| 中小企业要「进销存 + 财务 + 报表」一体化 | **frappe/erpnext** 或 **jishenghua/jshERP** | ERPNext 国际化、模块全；jshERP 中文本土化、进销存+财务一体 |
| 中国中小企业/代账，只需要财务记账与月末结转 | **jinbooks/jinbooks** | 账套、科目、凭证、月末结转、结账、工资，流程贴近中国会计实务 |
| 预算管理 / envelope 预算 | **actualbudget/actual**、**firefly-iii/firefly-iii** | 两者是个人财务定位，但预算模型与报表交互可借鉴到企业部门预算 |
| 桌面单机、发票/应收应付、多币种 | **Gnucash/gnucash** | 成熟的桌面复式记账 + 业务单据（AP/AR/发票） |
| 想直接借鉴「给 AI agent 用的财务 skill」写法 | **Geeksfino/finskills**、**JeffBrines/openfpa** | 前者是 SKILL.md 组织的金融分析技能集，后者是面向 coding agent 的 FP&A 工具包 |
| 方法论 | 本文第 9 节 | 三表勾稽、比率公式、月结流程、13 周现金流、杜邦分析 |

**一句话结论**：开源生态在「记账/复式记账/个人预算」上非常成熟，在「中国企业会计准则 + 自动报表 + 报税合规」上几乎没有高质量开源实现，这部分必须自建（科目映射 + 报表模板 + 校验规则），可大量借鉴 jshERP / jinbooks / ERPNext 的流程与数据模型。

## 1. 纯文本复式记账（Plain Text Accounting, PTA）

这一类的共同哲学：**账本 = 纯文本文件，复式记账，命令行/脚本生成报表**。对 agent 极其友好——可直接读、写、diff、版本管理、批量校验。

### 1.1 beancount/beancount

- **仓库**：`beancount/beancount` — <https://github.com/beancount/beancount>
- **一句话用途**：用文本文件做复式记账的 Python 记账系统，带账户树、指令语法、插件与导入器生态。
- **Star**：6,110（约 6.1k）
- **License**：GPL-2.0
- **最近更新**：2026-08-23（最近 push）
- **可复用点**：
  - 账户命名规范（`Assets:`, `Liabilities:`, `Income:`, `Expenses:`, `Equity:`）可直接作为 skill 的**科目树数据模型**；
  - 复式记账「有借必有贷、借贷必相等」的强约束，天然适合做 agent 的**数据校验层**；
  - 导入器（importer）设计思路可复用到「银行流水 CSV → 分录」自动化；
  - `bean-check` 式的账本校验 + Fava 报表，可作为「生成三大报表」的参考实现。

### 1.2 ledger/ledger

- **仓库**：`ledger/ledger` — <https://github.com/ledger/ledger>
- **一句话用途**：C++ 实现的双式记账命令行系统，plaintext accounting 的开山之作，报表能力强。
- **Star**：6,060（约 6.1k）
- **License**：GitHub 识别为 **Other / NOASSERTION**（未核实具体条款，使用前需查仓库 LICENSE）
- **最近更新**：2026-10-22（最近 push）
- **可复用点**：
  - `balance` / `register` / `print` 等命令的报表语义与输出格式，是设计「财务查询 DSL」的好参考；
  - 预算指令（`~ Monthly`）、定期交易、价格数据库（多币种换算）的思路；
  - 说明「账本即数据」的极简模型：少量字段即可支撑完整的资产负债表/利润表。

### 1.3 hledgerorg/hledger

- **一句话用途**：Haskell 写的 PTA 工具，提供 CLI、TUI 与 Web 界面，内置余额表、利润表、资产负债表、现金流等报表。
- **Star**：4,782（约 4.8k）

  - 预算报告（`--budget`）与 CSV 规则导入，适合复用到「预算 vs 实际」对比；

### 1.4 beancount/fava

- **仓库**：`beancount/fava` — <https://github.com/beancount/fava>

## 6. 财务分析方法论要点（速览）

1. **先业务，后财务**：先理解商业模式（收入怎么来、成本结构、现金周期），再看报表；否则比率没有意义。
2. **先质量，后比率**：判断收入确认是否激进、应收/存货是否异常、关联交易与一次性损益；再看 ROE、净利率。
3. **三层分析**：规模与趋势（同比/环比/三年 CAGR）→ 结构（收入/成本/费用占比）→ 驱动（量、价、客户、区域、产品）。
4. **对标**：与自身历史比、与预算比、与同行比（注意会计政策与业务模式差异）。
5. **落到现金**：利润 ≠ 现金，最终用经营现金流与自由现金流校验盈利质量。
6. **落到行动**：每个结论必须对应责任人与改善动作（提价、降本、催收、延付、去库存、融资）。

## 7. 对「公司经营管理」skill 的落地建议

- **确定性内核 + 模型判断**：比率、勾稽、现金流预测的算术必须用代码/表格实现（避免大模型算错），模型只负责解释、归因与建议。openfpa 的「finance kernel」思路值得照搬。
- **数据模型最小集**：主体（公司/账套）→ 期间 → 科目（资产/负债/权益/收入/费用）→ 凭证/分录（借贷）→ 业务单据（发票、收付款、合同）。beancount 的账户树 + GnuCash 的业务单据可拼出这个模型。
- **报表生成**：优先「科目余额表 → 报表模板映射」而不是逐项硬编码；参考 ERPNext 的报表口径与 hledger 的报表命令语义。
- **中国本土化**：科目表按《企业会计准则》常用科目建模板；凭证字（记/收/付/转）、月末结转、期初建账参考 jinbooks；进销存→凭证参考 jshERP。
- **质量闸门（skill 内置检查）**：借贷平衡、期初+发生=期末、三表勾稽、现金余额与银行对账差异、异常大额/负值/跨期凭证。
- **输出模板固定**：月度经营分析 = 摘要（3 条结论）+ 三表关键数 + 预算差异 Top5 + 现金流与现金水位 + 风险与动作清单。

## 9. 可直接沉淀为 skill 的知识

> 本节是 skill 的「知识内核」：公式与流程必须能被确定性执行；所有公式假设「期间一致、口径一致、单位一致」。

### 9.1 三大报表勾稽关系

**（1）资产负债表恒等式**

```
资产 = 负债 + 所有者权益
所有者权益 = 实收资本(股本) + 资本公积 + 其他综合收益 + 盈余公积 + 未分配利润
```

**（2）利润表 → 资产负债表（留存收益勾稽）**

```
期末未分配利润 = 期初未分配利润
               + 本期净利润
               − 提取盈余公积
               − 分配股利/利润
               ± 前期差错更正、会计政策变更等调整
```

**（3）现金流量表 → 资产负债表（现金勾稽）**

```
现金及现金等价物期末余额 = 现金及现金等价物期初余额 + 本期现金净增加额
资产负债表「货币资金」≈ 现金及现金等价物期末余额
（差异来源：受限资金、非现金等价物的定期存款/理财，需在附注说明）
```

**（4）现金流量表内部勾稽**

```
本期现金净增加额 = 经营活动现金流净额 + 投资活动现金流净额 + 筹资活动现金流净额
```

**（5）间接法：净利润 → 经营活动现金流**

```
经营活动现金流净额
  = 净利润
  + 非现金费用（折旧、摊销、减值准备、股份支付等）
  − 非现金收益（公允价值变动收益、投资收益等）
  ± 营运资本变动
     应收项目增加 → 减；减少 → 加
     存货增加     → 减；减少 → 加
     应付项目增加 → 加；减少 → 减
     预收/合同负债增加 → 加
```

**数值示例（用于 skill 自测）**：净利润 100，折旧 20，应收账款增加 30，存货减少 10，应付账款增加 15 →
经营现金流 = 100 + 20 − 30 + 10 + 15 = **125**。

**（6）交叉校验规则（skill 应内置的告警）**

- 借贷不平衡（借方合计 ≠ 贷方合计）→ 阻断；
- 期初余额 + 本期发生额 ≠ 期末余额 → 阻断；
- 净利润为正但经营现金流长期为负 → 提示应收/存货/收入确认风险；
- 现金净增加额 ≠ 货币资金变动（超阈值）→ 提示科目口径或未入账事项；
- 未分配利润变动与净利润+分红不匹配 → 提示遗漏结转或直接调整权益。

**（7）复式记账的本质**：任何资产增加，必然对应「另一项资产减少 / 负债增加 / 权益增加（含利润）」；三表勾稽本质是同一套分录的三种视角。

### 9.2 关键财务比率公式清单

> 阈值随行业/商业模式差异极大，下表「参考」仅作方向性提示，skill 中应支持按行业配置。

#### 偿债能力（短期）

| 指标 | 公式 | 含义 / 用途 | 参考 |
|---|---|---|---|
| 流动比率 | 流动资产 ÷ 流动负债 | 短期偿债能力 | 一般 >1，越接近 2 越稳（行业差异大） |
| 速动比率 | (流动资产 − 存货 − 预付款项) ÷ 流动负债 | 剔除存货后的即时偿债能力 | 一般 >1 |
| 现金比率 | (货币资金 + 交易性金融资产) ÷ 流动负债 | 最严格的短期偿债能力 | 0.2~0.5 常见 |
| 营运资本 | 流动资产 − 流动负债 | 短期资金缓冲绝对值 | >0 更安全 |

#### 偿债能力（长期）

| 指标 | 公式 | 含义 / 用途 | 参考 |
|---|---|---|---|
| 资产负债率 | 负债总额 ÷ 资产总额 | 整体杠杆与财务风险 | 制造业 40%~60% 常见 |
| 产权比率 | 负债总额 ÷ 所有者权益 | 债权人与股东资金相对关系 | 越低越稳 |
| 权益乘数 | 资产总额 ÷ 所有者权益 | 杠杆倍数（杜邦因子） | 与资产负债率同向 |
| 利息保障倍数 | EBIT ÷ 利息费用 | 经营利润覆盖利息的能力 | >3 较安全；<1 危险 |
| 现金利息保障倍数 | (经营现金流 + 利息 + 税) ÷ 利息 | 用现金视角看付息能力 | 越高越好 |
| 净负债率 | (有息负债 − 货币资金) ÷ 所有者权益 | 净杠杆 | 视行业 |

#### 营运能力

| 指标 | 公式 | 含义 / 用途 |
|---|---|---|
| 应收账款周转率 | 营业收入 ÷ 平均应收账款 | 回款效率 |
| 应收账款周转天数（DSO） | 365 ÷ 应收账款周转率（或 平均应收 ÷ 营业收入 × 365） | 平均回款天数 |
| 存货周转率 | 营业成本 ÷ 平均存货 | 库存周转效率 |
| 存货周转天数（DIO） | 365 ÷ 存货周转率 | 平均压货天数 |
| 应付账款周转天数（DPO） | 平均应付账款 ÷ 营业成本 × 365 | 平均付款天数 |
| 现金转换周期（CCC） | DSO + DIO − DPO | 资金被占用的净天数，越短越好 |
| 总资产周转率 | 营业收入 ÷ 平均总资产 | 资产使用效率 |
| 固定资产周转率 | 营业收入 ÷ 平均固定资产 | 产能利用效率 |
| 营运资本周转率 | 营业收入 ÷ 平均营运资本 | 营运资本效率 |

#### 盈利能力

| 指标 | 公式 | 含义 / 用途 |
|---|---|---|
| 毛利率 | (营业收入 − 营业成本) ÷ 营业收入 | 产品/服务的基础盈利空间 |
| 营业利润率 | 营业利润 ÷ 营业收入 | 主营业务的经营效率 |
| 净利率 | 净利润 ÷ 营业收入 | 最终盈利水平 |
| ROA（总资产收益率） | 净利润 ÷ 平均总资产 | 全部资产的赚钱能力 |
| ROE（净资产收益率） | 净利润 ÷ 平均所有者权益 | 股东回报（杜邦核心） |
| ROIC（投入资本回报率） | NOPAT ÷ 平均投入资本；NOPAT = EBIT × (1 − 税率)；投入资本 = 有息负债 + 所有者权益 − 现金及等价物 | 资本使用效率，可与 WACC 比较 |
| EBITDA 利润率 | EBITDA ÷ 营业收入；EBITDA = EBIT + 折旧 + 摊销 | 剔除资本结构与折旧政策影响 |
| EPS | 净利润 ÷ 加权平均普通股股数 | 每股盈利（仅股份公司） |

#### 成长能力

| 指标 | 公式 | 含义 |
|---|---|---|
| 营业收入增长率 | (本期营业收入 − 上期) ÷ 上期 | 规模扩张速度 |
| 净利润增长率 | (本期净利润 − 上期) ÷ 上期 | 盈利扩张速度 |
| 经营现金流增长率 | (本期经营现金流 − 上期) ÷ 上期 | 现金创造力趋势 |
| CAGR | (期末值 ÷ 期初值)^(1 ÷ 年数) − 1 | 复合年均增长率 |
| 可持续增长率（SGR） | ROE × 留存率 ÷ (1 − ROE × 留存率)；留存率 = 1 − 分红率 | 不增发、不改变杠杆下可支撑的增长 |

#### 现金流与现金质量

| 指标 | 公式 | 含义 |
|---|---|---|
| 经营现金流 / 净利润（净现比） | 经营活动现金流净额 ÷ 净利润 | >1 通常说明利润含金量较好 |
| 销售现金比率 | 经营活动现金流净额 ÷ 营业收入 | 每元收入的现金含量 |
| 自由现金流（FCF） | 经营活动现金流净额 − 资本性支出 | 可自由支配的现金 |
| FCFF | EBIT × (1 − 税率) + 折旧摊销 − 资本开支 − 营运资本增加 | 企业自由现金流（估值用） |
| FCFE | FCFF − 利息 × (1 − 税率) + 净借款 | 股东自由现金流 |
| 现金满足投资比率 | 近 N 年经营现金流 ÷ 近 N 年（资本开支 + 存货增加 + 现金股利） | 自我造血能力 |

#### 估值（仅上市公司，简要）

| 指标 | 公式 | 含义 |
|---|---|---|
| PE | 市值 ÷ 净利润（或股价 ÷ EPS） | 盈利倍数 |
| PB | 市值 ÷ 净资产 | 净资产倍数 |
| PS | 市值 ÷ 营业收入 | 收入倍数 |
| PEG | PE ÷ 净利润增长率(%) | 增长调整后的估值 |
| 股息率 | 每股股利 ÷ 股价 | 现金回报 |

### 9.3 月度结账流程（每月可执行 checklist）

> 目标：在 T+3~T+7 内完成结账，保证三表可勾稽、可解释、可追溯。每步都应记录「谁做、何时完成、调整分录清单」。

1. **交易截止（Cut-off）**：确认本月所有收入/费用单据已录入；检查跨期单据（月末最后几天）归属期间。
2. **银行与第三方对账**：银行流水、支付宝/微信/平台账户与账面核对，差异逐笔查明（未达账项、手续费、在途）。
3. **往来对账**：应收/应付明细与客户/供应商对账单核对；预收/预付、合同负债/合同资产复核。
4. **资产盘点与减值**：存货盘点与成本结转（差异分摊）；应收账龄分析并计提坏账准备；存货跌价准备。
5. **折旧与摊销**：固定资产折旧、无形资产摊销、长期待摊费用摊销（核对新增/处置资产）。
6. **计提（Accruals）**：工资社保公积金、奖金、利息、租金、水电、服务费、税费等「已发生未支付」项目。
7. **收入与成本配比**：按履约进度/交付确认收入；递延收入摊销；成本与收入同期间匹配。
8. **费用分摊**：按部门/项目/成本中心分摊共同费用（房租、IT、行政）；检查费用归属是否与预算口径一致。
9. **税务计提**：增值税及附加、企业所得税、印花税等计提，并与申报表数据核对（口径差异留说明）。
10. **外币折算**：外币货币性项目按期末汇率调整，汇兑损益入账。
11. **试算平衡**：全部科目「期初 + 本期借 − 本期贷 = 期末」；借贷合计相等。
12. **勾稽校验**：三表勾稽（见 9.1）+ 总账与明细账一致 + 现金与对账结果一致。
13. **结账与锁账**：冻结期间，禁止再改动已结账凭证；保留调整分录与审批记录。
14. **出报表**：资产负债表、利润表、现金流量表（月/累计）+ 管理报表（部门/产品/项目维度）。
15. **差异分析与归档**：预算 vs 实际、环比/同比差异归因，形成月度经营分析；资料归档留痕。

**skill 化建议**：把 1~15 做成带 `status`（未开始/进行中/完成/有异常）的清单，每步附「输入数据 → 校验规则 → 输出产物 → 异常处理」，并强制第 11~12 步通过才能进入第 13 步。

### 9.4 现金流预测方法

**（1）预测周期**：以 **13 周（一个季度）滚动**为主（周粒度，足够细、可执行），辅以 12 个月月度预测（战略视角）。

**（2）直接法（推荐日常经营使用）**

```
期末现金 = 期初现金
         + 销售回款（按合同/账龄/客户信用估算）
         − 供应商付款（按账期与采购计划）
         − 员工薪酬与社保
         − 税费（按申报日历）
         − 租金、利息、服务费等固定支出
         − 资本性支出（设备、装修、软件）
         ± 其他经营/投资收支
         + 融资流入（借款、增资） − 还款/分红
```

**（3）间接法（与利润表衔接，校验用）**

```
自由现金流 = 净利润 + 折旧摊销等非现金项 ± 营运资本变动 − 资本性支出
```

**（4）数据源与关键假设**

- 应收账龄表与历史 DSO（回款假设）；大客户集中度与合同里程碑；
- 应付账期与 DPO（付款假设）；固定费用清单（租金、薪酬、订阅）；
- 税费日历（增值税、所得税、社保公积金缴纳日）；
- 融资条款（还款日、利息、 covenants）。

**（5）13 周滚动表模板**

| 项目 | W1 | W2 | … | W13 |
|---|---|---|---|---|
| 期初现金 | | | | |
| 销售回款 | | | | |
| 其他流入（融资等） | | | | |
| 供应商付款 | | | | |
| 薪酬社保 | | | | |
| 税费 | | | | |
| 租金/利息/固定费用 | | | | |
| 资本性支出 | | | | |
| 净现金流 | | | | |
| 期末现金 | | | | |
| 最低现金水位告警 | | | | |

**（6）情景与敏感性**

- 基准 / 悲观（回款延迟 30 天、大客户流失、成本上涨）/ 乐观；
- 单因素敏感性：回款周期 ±15 天、收入 ±10%、毛利率 ±2pct 对期末现金的影响；
- 输出「现金缺口出现的周次」与「可动用杠杆」（催收、延迟付款、授信、保理、融资）。

**（7）闭环校验**

- 每周用实际数回填，计算预测误差（MAPE 或绝对偏差），归因到假设（回款/付款/费用）；
- 预测需与利润表、资产负债表联动（三表联动模型）：利润 → 应收/存货/应付 → 现金。

### 9.5 杜邦分析拆解

**（1）三因素模型**

```
ROE = 净利率 × 总资产周转率 × 权益乘数
    = (净利润 ÷ 营业收入) × (营业收入 ÷ 平均总资产) × (平均总资产 ÷ 平均所有者权益)
```

- **净利率** → 盈利能力（定价、成本、费用控制）
- **总资产周转率** → 营运效率（资产使用、周转速度）
- **权益乘数** → 财务杠杆（负债水平）

**数值示例**：净利率 5% × 总资产周转率 1.5 × 权益乘数 2.0 = **15%**。

**（2）五因素模型（把税与利息单独拆出）**

```
ROE = 税负率 × 利息负担 × 营业利润率 × 总资产周转率 × 权益乘数
    = (净利润 ÷ 税前利润)
    × (税前利润 ÷ EBIT)
    × (EBIT ÷ 营业收入)
    × (营业收入 ÷ 平均总资产)
    × (平均总资产 ÷ 平均所有者权益)
```

**（3）分析步骤（skill 可直接照做）**

1. 计算 ROE 并做趋势（近 3~5 年）与同行对比；
2. 拆三因素，看 ROE 变化由哪个因子驱动（利润？周转？杠杆？）；
3. 拆五因素，定位是税负、利息、经营利润率还是杠杆；
4. 与现金流交叉验证：ROE 上升若靠杠杆或应收/存货扩张，需警惕质量；
5. 输出「可提升空间 + 对应动作」（提价/降本/加速周转/降杠杆/优化税负）。

**（4）局限与注意事项**

- 高杠杆可以「做高」ROE，但增加财务风险；金融、地产、重资产行业不可与轻资产行业直接比；
- ROE 不反映现金流与风险，建议同时看 ROIC 与 FCF；
- 会计政策（折旧、存货计价、研发资本化）会影响可比性，跨公司比较前先统一口径。

### 9.6 管理会计补充：本量利、保本点与预算差异

**（1）本量利（CVP）**

```
边际贡献 = 销售收入 − 变动成本
单位边际贡献 = 单价 − 单位变动成本
边际贡献率 = 单位边际贡献 ÷ 单价（= 边际贡献 ÷ 销售收入）
保本销量 = 固定成本 ÷ 单位边际贡献
保本销售额 = 固定成本 ÷ 边际贡献率
安全边际率 = (实际/预计销售额 − 保本销售额) ÷ 实际/预计销售额
目标利润销量 = (固定成本 + 目标利润) ÷ 单位边际贡献
经营杠杆系数 DOL = 边际贡献 ÷ EBIT（也等于 EBIT 变动率 ÷ 收入变动率）
```

**（2）预算差异分析**

```
总差异 = 实际数 − 预算数（有利 F / 不利 U）
价格差异 = (实际单价 − 标准单价) × 实际数量
数量差异 = (实际数量 − 标准数量) × 标准单价
收入差异 = 价格差异 + 数量差异（多产品时再加结构差异）
固定制造费用：耗费差异 = 实际 − 预算；产量差异 = (预算产量 − 实际产量) × 标准分配率
```

**（3）预算管理流程（与 skill 结合）**

1. 战略目标 → 年度经营目标（收入、毛利、费用、现金）；
2. 自上而下定盘子，自下而上编部门预算，两轮对齐；
3. 月度滚动预测（Rolling Forecast），季度重排年度预算；
4. 月度「预算 vs 实际」差异分析，Top 差异必须归因到量/价/结构/一次性因素；
5. 差异 → 行动项（责任人 + 期限），纳入经营例会跟踪。

**（4）财务建模（三表联动）最小公式集**

```
收入 = 销量 × 单价（或 客户数 × ARPU）
毛利 = 收入 − 变动成本（收入 × 变动成本率）
EBIT = 毛利 − 固定费用（人力 + 租金 + 市场 + 研发 + 管理）
净利润 = (EBIT − 利息) × (1 − 税率)
应收账款 = 收入 × DSO ÷ 365；存货 = 营业成本 × DIO ÷ 365；应付账款 = 营业成本 × DPO ÷ 365
资本开支 = 收入 × CapEx 比率（或按项目清单）
自由现金流 = 净利润 + 折旧摊销 − 营运资本增加 − 资本开支
企业价值（DCF）= Σ FCFF_t ÷ (1 + WACC)^t + 终值 ÷ (1 + WACC)^n
终值（永续增长）= FCFF_(n+1) ÷ (WACC − g)
WACC = E ÷ (D + E) × Re + D ÷ (D + E) × Rd × (1 − 税率)
```

**（5）skill 质量自检清单**

- [ ] 所有比率分子/分母来自同一期间、同一合并口径；
- [ ] 平均余额使用「(期初 + 期末) ÷ 2」（或明确说明用期末数）；
- [ ] 负值/零分母有兜底（如所有者权益为负时 ROE 无意义，需标注）；
- [ ] 一次性损益（政府补助、资产处置）单独列示，不混入经常性利润；
- [ ] 现金流预测与三表联动，且每周回填校准；
- [ ] 输出明确「数据来源、期间、单位、币种、未核实项」。
